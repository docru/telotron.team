# LLM-инженер · интеграция ИИ (11)

Роль **прикладной интеграции LLM** в продукт Telotron: сервисы на готовых моделях (Caila и др.), промпты, качество, стоимость, безопасность данных. **Обучение foundation-моделей не входит** в текущий этап.

На старте роль **может совмещаться** с разработчиком; отдельный фокус — когда параллельно несколько AI-сервисов (КБЖУ, поиск клиентов и т.д.).
