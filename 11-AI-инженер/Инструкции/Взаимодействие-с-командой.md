# Взаимодействие с командой

## Роли в цикле AI-сервиса

| Роль | Вклад |
|------|--------|
| **LLM-инженер (11)** | Модель, промпт, eval, cost, guardrails, контракт ответа |
| **Разработчик (03)** | Модуль Laravel/PWA, jobs, API, UI вызова, тесты кода |
| **Архитектор (10)** | Граница модуля, куда жить AI-контуру, ADR при сквозном изменении |
| **Директор / PO (01 / 03)** | Нужен ли сервис, приоритет, критерии ценности |
| **Маркетолог (02)** | Обещания в коммуникации без «магии»; упаковка аддона |
| **UI/UX (08)** | Экраны загрузки/ошибки/результата ИИ |
| **Тестировщик (09)** | Сценарии UI и регрессия продукта; eval качества модели — зона 11 |
| **Юрист (07)** | ПДн в промптах, формулировки согласий при ИИ-обработке |
| **Сисадмин (04)** | Ключи, лимиты сети, алерты runtime |
| **Бухгалтер (05)** | Учёт расходов на API при масштабе (по запросу) |

## Ритм

- **Старт AI-сервиса:** LLM-инженер + разработчик + (при новом модуле) архитектор — цель, контракт I/O, провайдер, оценка $ / запрос.
- **Перед prod:** [Чеклист-перед-AI-сервисом](Чеклист-перед-AI-сервисом.md); golden set прогнан; fallback описан.
- **После выкладки:** неделя наблюдения cost/error rate; правка промпта = версия + короткий eval.

## Эскалации

| Ситуация | Кому |
|----------|------|
| Провайдер недоступен / резкий рост цены | Сисадмин + директор; временный disable фичи |
| В промпт попадают лишние ПДн | Юрист + архитектор; стоп до фикса |
| «ИИ врёт» в критичном сценарии (деньги, здоровье) | Директор; сузить scope или выключить |
| Спор «быстро в UI без eval» | Директор; без eval в prod — только stage |

## Чат роли

См. `Команда/Чаты по ролям.md` — префикс **`[11 LLM]`**.

Шаблон:

`Работаем как LLM-инженер. Папка Команда/11-AI-инженер/. Цель: … (модель / промпт / eval / стоимость).`

## Совмещение с разработчиком

Если один человек — в чате явно: **«сейчас AI-слой (промпт/eval)»** vs **«сейчас код модуля»**. Не смешивать «подкрутил промпт» и «переписал API» без фиксации версии промпта.
