## Сентябрь — середина ноября 2026: модуль продаж (I-001)

**Цель:** к **концу октября — середине ноября** — рабочий [I-001](../../backlog/инициативы/I-001-модуль-продаж.md) для тренеров ([E-006](../../backlog/эпики/E-006-crm-тренера.md)).

Порядок этапов:

1. **CRM** (воронка лидов).  
2. **Зона входа лидов** — форма ОС, квиз, внесение старых клиентов.  
3. **Кроссплатформенность** — VK, OK, MAX, Telegram.  
4. **ИИ-помощник** для продвижения.

**Фокус основателя:** разработка. Продвижение — минимально до появления компетентного продажника (**знамение**, DEC-008).

## Декабрь 2026: дистанционное сопровождение

**Цель:** инструменты удалённой работы тренера с клиентом:

- трансляция выполнения упражнений клиентом;
- видеозапись выполнения клиентом;
- видеозапись для конструктора упражнений.

Юрист: согласия / ПДн по видео **до** массового пилота.
