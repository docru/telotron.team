# Цели

## Личные и служение

1. **Главная цель** — высвободить время, чтобы развивать **гимназию**: исследовать и писать по **христианской педагогике**.
2. Нужны **финансы** для развития гимназии.
3. Хотим купить дом и 2 машины; ездить по стране туристами.
4. Найти лучших специалистов для Елисеи.
5. Хорошая мощная компьютерная техника.
6. Есть чувство, что пока будет развиваться этот бизнес, смогу дорасти до директора гимназии.

## Смысл Telotron (DEC-008 · 2026-09-19)

1. Проект — **инициатива Бога** по **обеспечению**, чтобы освободить время для **служения**.
2. **Знамение** этой инициативы: появится человек, **компетентный в продажах**, который **активно возьмётся за продвижение**.
3. **Задача основателя сейчас** — **сосредоточиться на разработке** (не быть основным «отделом продаж»).

Канон-план: [План-2026-09-фокус-разработка](План-2026-09-фокус-разработка.md).

## Бизнес-ориентир (долгосрок)

- Цель масштаба: порядка **5000** подключённых тренеров.
- Экономика и личный доход — пересчёт под **клиенто-день + аддоны** ([DEC-007](05-Журнал%20управленческих%20решений.md)); старые «5000 ₽/мес × тариф» — **не канон**.
- Ориентир: устойчивый recurring, достаточный на цели выше (гимназия, семья) — уточнять по факту платежной модели.
