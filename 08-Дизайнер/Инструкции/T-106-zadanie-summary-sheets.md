## Цель

Экран профиля = **короткий список блоков** с текстом-итогом. Тап по блоку → маленькая форма в sheet. Без якорей и без общего sticky «Сохранить».

---

## Канон UI

```
← Кабинет                         ← Pro (PF-04)
Кабинет / Профиль

Аккаунт
  +7 ··· ···-12-34                      ← read-only, без sheet edit

Анкета
  Иван Иванов · муж · 12.03.90      ›   ← тап → sheet

Имя для клиентов                    ← только Pro
  Иван П.                           ›

Мои часы                            ← только Pro
  07:00–22:00                       ›

Вход
  Отпечаток / Face ID: подключено   ›   ← или inline CTA

Уведомления
  MAX · Telegram · …                ›   → /notification-channels

Приватность
  Email для запроса удаления        ›   ← sheet с одним полем + пояснением

[ Выйти ]                           ← отдельная кнопка, не блок-сводка
```

Empty-сводка: приглушённо `Не заполнено` / `Не настроено` — тап всё равно открывает форму.

### Взаимодействие

| Зона | Действие |
|------|----------|
| Основная площадь блока (заголовок + сводка) | открыть sheet / переход |
| **›** справа | то же (подсказка) |
| Аккаунт (телефон) | **не** sheet редактирования (read-only) |
| Уведомления | переход на `/notification-channels` (не второй sheet) |
| Выйти | отдельный CTA внизу |

Карандаш не обязателен.

### Sheet

- Bottom sheet на 360–430px; wide — Dialog ок.
- **Одна тема = одна форма** (вся анкета целиком; часы отдельно; display name отдельно). Не дробить анкету на 4 sheet.
- CTA в sheet: **«Готово»** / «Сохранить» → закрытие + обновление сводки на странице.
- Гейт Client (PF-03): без смены смысла — после save в sheet гейта: успех + увод; обычный edit анкеты: stay + «Анкета сохранена».

### Убрать из среза 1

- Ряд **якорей** сверху.  
- **Sticky «Сохранить»** на всю страницу.  
- Длинные развёрнутые формы всех секций сразу на странице (кроме read-only аккаунта и кнопки Выйти).
