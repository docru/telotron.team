## 2. Обязательный канон (не ослаблять)

1. **Словарь:** занятия = **Расписание**; фиксация клиентом = **Дневник(и)**. Не называть эти экраны «Календарь».
2. Pro tabs: **Клиенты · Расписание · Кабинет · Поддержка**; default = **Клиенты**; без Главной/Ещё.
3. Hub клиента = **сводка** (кто → ближайшее → строка недели → плитки), не 4×2 таба на входе.
4. Client home: неделя → (занятие) → **Прогресс** (+ mini-вес ≥3) → ряд Тренировки/Питание/Трекеры.
5. Client дневник: **день + полоска недели**; пустые даты приглушены, тап → empty.
6. Pro Расписание: **сетка часов**; дни 3→5→7; ось **Мои часы** / дефолт 07–22; якорь сегодня/сейчас.
7. Мастера онбординга — **убрать** из UI (A9); «Знакомство с Телотрон» — убрать.
8. Soft nudges — **не** в этом тикете → [T-102](../../backlog/бэклог/T-102-ux-виджет-мягких-подсказок.md).

## 5. Не делать

- 5-й таб «Прогресс» у Client.

- Полные 24 часа на оси Расписания без «Моих часов».
- Возврат мастеров К/П или пункта «Знакомство с Телотрон».
- Виджет «совет дня» в рамках T-101.
