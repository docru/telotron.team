```
│   ─ body ─                          │
│   Овсянка 200 г · 320 ккал      ✎ 🗑│
│   Яйцо 2 шт · 100 ккал          ✎ 🗑│
│   Очистить приём                    │
├─────────────────────────────────────┤
│ ▶ Обед                  [📷] [＋]   │
│   Добавить блюдо                    │  ← EMPTY-01 (схлопнут: строка видна)
├─────────────────────────────────────┤
│ ▶ Ужин                  [📷] [＋]   │
│   —                                 │  ← нет КБЖУ / нет блюд: без ложных 0

│   Добавить блюдо                    │

```

**Правила**

| ID | Правило |
|----|---------|
| KBJU-01 | Строка КБЖУ на плашке, если ≥1 блюдо с цифрами; иначе не показывать «0 ккал» как факт (null → скрыть или «—» по контракту A) |
| EMPTY-01 | Пустой приём: текст **«Добавить блюдо»** (E-005). Тап по тексту **или** **＋** → lightbox create |
| PHOTO-01 | Фото приёма на плашке как сейчас; не в lightbox блюда |
| LIST-01 | В строке блюда: имя · вес · ккал порции (если есть) |
| NO-INLINE | Inline-compose в карточке **убрать** |

## 2. Lightbox · блюдо (create / edit)

Паттерн: **Dialog** (как `NutritionMealPhotoLightbox`), на 360px — max высота + scroll body; не bottom sheet профиля.

### 2.1. База

```
┌─────────────────────────────────────┐
│ Добавить блюдо · Завтрак         ✕  │  ← edit: «Изменить блюдо · …»
├─────────────────────────────────────┤
│ Название                            │
│ ┌─────────────────┐ ┌────┐ ┌────┐  │
│ │ Овсянка с …     │ │ 🎙 │ │ ║║ │  │  ← HIT-01: mic + barcode ≥44×44
│ └─────────────────┘ └────┘ └────┘  │
│ ┌───────────────────────────────┐  │
│ │ Овсянка быстрого приготовл.   │  │  ← SUGGEST-01
│ │   350 ккал / 100 г            │  │
│ │ Овсяные хлопья                │  │
│ └───────────────────────────────┘  │
│                                     │
│ Порция                              │  ← AMOUNT-01: не «Вес» (лжёт при мл/шт)
│ [ 200 ] [ г ▾ ]                     │  ← placeholder пустой; смысл в label + ед.
│                                     │
│ КБЖУ порции                         │
│ ккал [ 700 ]  Б [50]  Ж [12]  У [… ]│  ← MACROS-01: авто из продукта; editable
│ источник: база / штрихкод / вручную │  ← caption muted, опционально
├─────────────────────────────────────┤
│ [ Отмена ]            [ Сохранить ] │
└─────────────────────────────────────┘
```

**Правила**

| ID | Правило |
|----|---------|
| HIT-01 | Mic и barcode — отдельные кнопки, min **44×44** css px |
| SUGGEST-01 | Debounce; список под полем; выбор → name + нутриенты на 100 г → пересчёт по порции |
| AMOUNT-01 | Label **«Порция»** (г / мл / шт). **Не** «Вес». Placeholder **не** дублировать («Кол-во» / «Вес») — пустой input; единица справа несёт размерность |
| WEIGHT-01 | Не подставлять 100 г тихо (alias AMOUNT default); пустой `amount` / валидация — по контракту A |
| MACROS-01 | Поля опциональны: сохранить блюдо можно без КБЖУ |
| VOICE-01 | Mic пишет в название; copy Client «ты» (как Voice) |
| SAVE-01 | Успех → закрыть lightbox → обновить плашку/список |
| EDIT-01 | Карандаш на блюде → тот же lightbox prefilled |

### 2.2. Состояния lightbox

| Состояние | UI |
|-----------|-----|
| Suggest loading | Skeleton / spinner в списке подсказок |
| Suggest empty | Список скрыт; можно вводить вручную |
| Offline | Suggest/barcode lookup недоступны → toast; ручной ввод по контракту A |
| Saving | CTA disabled + spinner |
| Validation | Inline / toast: пустое имя; порция по правилам A |

## 3. Сканер штрихкода (поверх lightbox)

```
┌─────────────────────────────────────┐
│ Штрихкод                         ✕  │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │                                 │ │
│ │      (live camera preview)      │ │  ← VIEW-01 ~70% высоты модалки
│ │                                 │ │
│ │ ═══════════════                 │ │  ← полоска / рамка по центру
│ │                                 │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [ Загрузить фото штрихкода ]        │  ← UPLOAD-01
│                                     │
│ Разреши доступ к камере в           │  ← PERM-01 только если denied / нет трека
│ настройках браузера — или загрузи   │
│ фото.                               │
└─────────────────────────────────────┘
```

**Правила**

| ID | Правило |
|----|---------|
| STACK-01 | Сканер открывается **поверх** lightbox; ✕ / успех → назад в lightbox |
| VIEW-01 | Превью камеры занимает большую часть; горизонтальная полоска = зона штрихкода |
| PERM-01 | **Нет** отдельного экрана permission. Первый заход → системный prompt ОС. При отказе — тот же layout + muted copy + upload |
| UPLOAD-01 | File picker image → decode (клиент или бэк — A) → тот же success-path |
| OK-01 | Продукт найден → закрыть сканер → lightbox с name + КБЖУ (+ вес если известен) |
| MISS-01 | Не найден → toast «Продукт не найден» → lightbox; ручной ввод |
| BUSY-01 | Во время lookup — overlay spinner на preview / disable upload |

**Поток**

```text
Lightbox → tap barcode
  → Scanner modal
      → getUserMedia (OS prompt)
      → scan OK | upload OK
          → API lookup
              → hit → fill lightbox
              → miss → toast + lightbox empty macros
      → deny camera → copy + upload only
```

## 6. T-110 · ИИ-ансамбль (дополнение к lightbox)

Сканер штрихкода (§3) в потоке ввода еды **не используется** (T-110): слот barcode → **лупа+ИИ**.

### 6.1. Поле названия + ИИ

```
┌─────────────────────────────────────┐
│ Название                            │
│ ┌─────────────────┐ ┌────┐ ┌────┐  │
│ │ Гречка с котл…  │ │ 🎙 │ │ 🔍ИИ│  │  ← AI-01: лупа+ИИ; inactive→active после паузы
│ └─────────────────┘ └────┘ └────┘  │
│ ┌───────────────────────────────┐  │
│ │ Гречка отварная (пользоват.)  │  │  ← SUGGEST: by_users / ai_estimates
│ │   110 ккал / 100 г            │  │
│ │ ── Искать с ИИ ──             │  │  ← AI-02: отдельно от hits / empty
│ └───────────────────────────────┘  │
│                                     │
│ К180 Б12 Ж10 У18 ИИ                 │  ← AI-03: компакт; тап → лайтбокс ДИ
│ ккал [ … ]  Б […]  Ж […]  У […]     │
└─────────────────────────────────────┘
```

| ID | Правило |
|----|---------|
| AI-01 | Лупа+ИИ вместо barcode; активна после паузы набора (≥ `SUGGEST_IDLE_MS`) и непустого имени |
| AI-02 | «Искать с ИИ» в конце выдачи и в empty state; визуально не как обычный hit |
| AI-03 | Компакт `К… Б… Ж… У… ИИ` над полями; тап → Dialog со всеми 95% ДИ + дисклеймер (не медицина) |
| AI-04 | Лоадер во время suggest/ансамбля; сбой → «не удалось найти»; лимит 50/сутки — тихо |
| AI-05 | Ручная правка любого макроса → снять ИИ-маркер и ДИ |

### 6.2. Лайтбокс ДИ

```
┌─────────────────────────────────────┐
│ Оценка ИИ · 95% ДИ               ✕  │
├─────────────────────────────────────┤
│ Ориентир по названию, не этикетка.  │
│ ккал  160–200                       │
│ Б     10–14 г                       │
│ Ж     8–12 г                        │
│ У     15–22 г                       │
│ (на 100 г)                          │
└─────────────────────────────────────┘
```
