## 3. Pro · Расписание · сетка часов

### 3.1. Шапка

```
┌─────────────────────────────────────┐
│ Расписание              [ + Занятие]│  ← CTA компактно в шапке
│ ‹  Пн 28 – Ср 30 июл  ›   [Сегодня] │  ← сдвиг окна дней
└─────────────────────────────────────┘
```

- Имя экрана: **Расписание** (не Календарь).
- Убрать лишний lead про «только онлайн», если уже есть offline-banner в shell.

### 3.2. Сетка (дни × часы)

**Колонки дней — отзывчиво:**

| Ширина viewport (ориентир) | Дней в окне |
|----------------------------|-------------|
| ~360–599px | **3** |
| ~600–899px | **5** |
| ~900px+ | **7** |

**Ось Y:** часы из **«Мои часы»** профиля; иначе **07:00–22:00**. Вертикальный скролл. При открытии — якорь **сегодня** + **текущий час** (или ближайший слот).

```
Пример 360px · 3 дня · фрагмент

        │  Пн 28  │  Вт 29  │  Ср 30  │
────────┼─────────┼─────────┼─────────┤
 10:00  │         │████ Анна│         │
 11:00  │████ Иван│         │         │
 12:00  │         │         │         │
  ...   │  (скролл вверх/вниз)        │
─── now ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  ← линия «сейчас» на сегодня
 18:00  │         │         │████ Груп│
```

- Слот: цвет/тип как сейчас (individual/group); на узкой колонке — короткое имя или инициалы, тап → детали.
- Пустой час — тап (если online) → создать занятие на это время (если уже есть в продукте; иначе только «+»).

**Вне scope среза 0 как отдельный режим:** старые равноправные agenda/day/week/month toolbar для Pro — заменить/свести к сетке (+ опционально список дня позже). Не тащить 4-режимный сегмент как основной UX.

## 4. Pro · Кабинет · B1 title stack

**Хабы Кабинет и Поддержка** — не «Ещё»-свалка.

### 4.1. Корень «Кабинет»

```
┌─────────────────────────────────────┐
│ Кабинет                             │  ← крупный H1 раздела
│ Подготовка к работе                 │  ← короткий lead (опц.)
│                                     │
│ ┌ Тренировки ────────────────── › ] │
│ ┌ Планы питания ─────────────── › ] │
│ ┌ Группы ────────────────────── › ] │
│ ┌ Профиль ───────────────────── › ] │
└─────────────────────────────────────┘
│ Клиенты │ Расписание │Кабинет│Поддер│
```

### 4.2. Вложенный экран (пример · Профиль)

```
┌─────────────────────────────────────┐
│ ← Кабинет                           │
│ Кабинет / Профиль                   │  ← title stack (не веб-крошки)
│                                     │
│ … поля профиля …                    │
│                                     │
│ Мои часы                            │
│ Начало  [ 07:00 ]  Конец [ 22:00 ]  │  ← влияет на ось Расписания
│ Подсказка: сетка покажет только     │
│ эти часы. По умолчанию 07:00–22:00. │
└─────────────────────────────────────┘
```

- Профиль: пункт в **Кабинете** + **компактный аватар** справа в шапке shell Pro — оба ведут на один экран профиля (B2 · вариант A). Не оставлять профиль *только* в шапке без пункта в Кабинете.
- Планы питания: список + **«+»** справа сверху; форма не на весь экран по умолчанию (A4).

### 4.3. Корень «Поддержка»

## 6. Client · Дневник · A7 вид

Единый паттерн для **Тренировки / Питание / Трекеры** (контент дня разный, chrome один).

**Default Питание:** сразу **дневник** (`sub=diary`), не календарь (A6).

```
┌─────────────────────────────────────┐
│ Питание                             │
│ [ Дневник ] [ Назначения ] …        │  ← дневник первым / default
│                                     │
│  Пн  Вт  Ср  Чт  Пт  Сб  Вс         │  ← полоска текущей недели
│  28  29 [30] 31   1   2   3         │
│  ·   ·   ●   ○   ○   ·   ·          │
│  ▲есть  ●выбран  ○пусто(приглушён)  │
│                                     │
│  Среда, 30 июля                     │
│  … записи дня …                     │
│                                     │
│  — или empty —                      │
│  В этот день записей нет            │
│  [ + Добавить ]  (если уместно)     │
└─────────────────────────────────────┘
```

| Состояние даты в полоске | Визуал | Тап |
|--------------------------|--------|-----|
| Есть записи | обычный / точка | открыть день |
| Нет записей | **приглушён** | разрешён → empty в теле |
| Выбранный | акцент (ring/primary) | — |
| Сегодня | отличить от выбранного (если не совпали) | — |

**Убрать** как основной UX: сегмент режимов agenda / day / week / month на Client-дневниках.

Имена вкладок/экранов: **Дневник…**, не «Календарь».
