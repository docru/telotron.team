## 1. Цель среза

Сделать оболочку Pro по решению директора (A2 + A3 + A9 UI):

1. Убрать **Главную** и **Ещё** из bottom tabs.  
2. Табы: **Клиенты · Расписание · Кабинет · Поддержка**.  
3. После входа открывать **Клиенты**.  
4. Разнести содержимое «Ещё» на **Кабинет** и **Поддержка**.  
5. **Удалить из UI** мастера онбординга К/П и пункт «Знакомство с Телотрон».

## 2. Scope (делать)

### 2.1. Bottom tabs + default (A2, A3)

| Было | Стало |
|------|--------|
| Главная · Расписание · Клиенты · Ещё | **Клиенты · Расписание · Кабинет · Поддержка** |
| Старт / home → часто Главная | После login / `/` → **Клиенты** |

- Маршруты и `matchKeys` табов поправить так, чтобы вложенные экраны подсвечивали нужный таб.  
- Экран «Главная» Pro: убрать из навигации (редирект на Клиенты допустим).  
- Имя экрана расписания в UI: **Расписание** (не «Календарь»).

Wireframe: §1.1.

### 2.2. Хаб «Кабинет»

Корень таба — список входов (не свалка как старое «Ещё»):

- Тренировки  
- Планы питания  
- Группы  
- Профиль  

Смысл: место, где тренер **готовится к работе** сам.

Wireframe: §4.1.  
**Title stack** (Кабинет / текущий экран) — желательно в этом срезе минимально (H1 + «Назад»); полный polish — срез 5 / B1, если не успеете.

### 2.3. Хаб «Поддержка»

- Обратная связь  
- Опросы  
- **Нет** пункта «Знакомство с Телотрон»

Wireframe: §4.3.

### 2.4. Снятие мастеров онбординга (A9 · UI-first)

Убрать из Pro UI:

- coach-bar / spotlight / баннеры мастера К и П;  
- маршрут `/more/onboarding` (или аналог) и пункты меню на него;  
- все entry points «продолжить знакомство» / шаги мастера в shell.

**Допустимо в срезе 2:** UI-first — API dismiss/steps могут остаться мёртвыми до согласования с архитектором (не блокер merge, если UI чистый).  
**Не делать здесь:** виджет мягких подсказок → [T-102](../../backlog/бэклог/T-102-ux-виджет-мягких-подсказок.md).

Связь: [T-060](../../backlog/сделано/T-060-pro-onboarding-k-p.md) superseded; [T-065](../../backlog/бэклог/T-065-pro-onboarding-порядок-подготовка-клиент.md) не развивать как мастер.

### 2.5. Профиль (B2 · вариант A)

- В **Кабинете** — пункт «Профиль».
- В шапке Pro — **компактный аватар** (или иконка профиля) справа → **тот же** экран профиля.
- **Не** убирать вход из шапки полностью (discoverability настроек / выхода).
- **Не** оставлять профиль только в шапке без пункта в Кабинете.
