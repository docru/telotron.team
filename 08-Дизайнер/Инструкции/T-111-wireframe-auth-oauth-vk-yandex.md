## Поток · обзор

```text
Pro:
  /login → OAuth или «по телефону» → [подтверждение имени+телефона?] → reg или кабинет

Client:
  нет «уже входил» → экран инвайта
  есть «уже входил» → /login как Pro
  reg не готова + инвайт в storage → /login (без экрана инвайта)
  reg не готова + инвайта нет → экран инвайта
```

## A. Pro · `/login`

```
┌─────────────────────────────────────┐
│ Вход                                │
├─────────────────────────────────────┤
│                                     │
│  [  Войти через Яндекс  ]           │
│  [  Войти через VK      ]           │
│                                     │
│  Войти по телефону                  │  ← text link, не primary
│                                     │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─     │  ← только если show Passkey
│  [ Войти по отпечатку / Face ID ]   │
│                                     │
│  Продолжая, вы соглашаетесь с       │
│  пользовательским соглашением.      │
```

**Заметки:** кнопки OAuth равноправны (Q3). Телефон — ссылка (Q4). Оферта/18+ остаются на этом экране (как E-003).

## F. Регистрация (первый OAuth, User нет)

Как текущий `/register`, но:

- имя/фамилия **предзаполнены** из провайдера (Q13), поля редактируемые;
- телефон уже известен (из OAuth или после OTP);
- согласия — как сейчас.

```
┌─────────────────────────────────────┐
│ Регистрация                         │
├─────────────────────────────────────┤
│  ☑ … согласия …                     │
│  Имя     [ Мария        ]           │
│  Фамилия [ Иванова      ]           │
│  Пол     [ … ]                      │
│  [ Создать аккаунт ]                │
└─────────────────────────────────────┘
```

## G. Кабинет · профиль · способы входа

```
┌─────────────────────────────────────┐
│ Способы входа                       │
├─────────────────────────────────────┤
│  Телефон  +7 (900) …    подтверждён │
│                                     │
│  Яндекс   привязан      [ Отвязать ]│
│  VK       не привязан   [ Привязать]│
│                                     │
│  Passkey  …             [ … ]       │
└─────────────────────────────────────┘
```

- **Привязать** → OAuth → подтверждение **имя + телефон** → ок или ошибка «уже у другого» (Q11).  
- **Отвязать** → сначала наш OTP на телефон (Q12), потом отвязка.
