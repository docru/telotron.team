## Канон UI

```
← К шаблонам                    [ + Задание ]
Название шаблона [______________]

≡  Присед · 3×10                         🗑
≡  Жим · 4×8 · 40 кг                     🗑
≡  Планка · 3×45с                        🗑

              [ Сохранить шаблон ]
```

### Список

| Правило | Деталь |
|---------|--------|
| Содержание строки | Коротко: **название упражнения** + параметры (напр. `3×10`, вес/время если есть). **Без** комментария в списке |
| Порядок | **Drag-and-drop** за ручку **≡** слева (не за всю строку — конфликт со скроллом на мобиле) |
| Стрелки ↑↓ | Убрать или оставить только как a11y-fallback (не обязательны в UI) |
| Edit | **Тап по основной части строки** (название / summary) → открыть sheet. **Без** иконки карандаша |
| Delete | Только **корзина** справа; confirm (лучше Dialog, не обязательно в этом задании если уже есть confirm) |
| Hit-areas | ≡ = drag; 🗑 = delete; остальное = edit |

### Sheet (создание / редактирование)

- **Bottom sheet** на 360–430px (не крошечный modal по центру); на wide — Dialog ок.
- Поля: упражнение, комментарий, подходы / повторы / вес / время / отдых (как сейчас в форме; 2 ряда полей сохранить).
- CTA в sheet: **«Готово»** / «Сохранить задание» (закрывает sheet, обновляет список).
- **«Сохранить шаблон»** — на **странице списка**, не путать с CTA sheet.
- **«+ Задание»** — **сверху справа** (рядом с уходом «К шаблонам» слева). Открывает sheet пустого задания.
