> **«Мои часы» (T-101) снять** — ось из расписания дня или **08:00–20:00**, если день не задан. Не путать с «длительностью занятия» в настройках записи.

---

## Поток · обзор

```text
Pro:
  Расписание (сетка)
    → день без расписания: применить шаблон дня / недели / копировать / задать вручную
    → день с расписанием: править start/end/перерывы; создать индив/группу из слота
  Шаблоны: список шаблонов дня + один шаблон недели
  Настройки: длительность слота + дедлайн самозаписи (без «Мои часы»)

Client:
  Календарь тренера / день
    → свободные слоты индив (с дедлайном) → самозапись сразу
    → группа с местами → записаться / отменить (до конца группы)
  Запись от тренера → подтвердить / отклонить
```

## A. Pro · Расписание · день **без** расписания

Ось Y: **08:00–20:00**. Запись клиентом закрыта. Занятий на день может не быть.

```
┌─────────────────────────────────────┐
│ ‹  Пт 15 авг  ›          Сегодня    │
├─────────────────────────────────────┤
│ Расписание не задано                │
│ Клиенты записаться не смогут        │
│                                     │
│ [ Применить шаблон дня ]            │
│ [ Применить шаблон недели ]         │  ← только пустые дни с сегодня
│ [ Скопировать с другого дня ]       │
│ [ Задать вручную ]                  │
│                                     │
│ ─ сетка 08:00–20:00 (пустая) ─      │
│ …                                   │
└─────────────────────────────────────┘
```

**Заметки:** шаблон поверх уже заполненного дня — нельзя (отдельный toast/disabled). Прошедшие дни — применить нельзя.

## B. Pro · Применить шаблон дня

```
┌─────────────────────────────────────┐
│ Применить шаблон          [ Отмена ]│
├─────────────────────────────────────┤
│ Выберите шаблон                     │
│ ○ Будни 10–19                       │
│ ○ Утро 07–12                        │
│ ○ Выходной                          │
│                                     │
│ Применить к:                        │
│ ● Только этот день                  │
│ ○ Несколько дат…                    │  ← только сегодня+будущее, без уже заполненных
│                                     │
│ [ Применить ]                       │
└─────────────────────────────────────┘
```

После применения — **снимок**, связи с шаблоном нет. День можно править (экран C).

## C. Pro · День **с** расписанием · правка

Ось Y = start–end дня. Перерывы — заштрихованные/пустые блоки без слотов.

```
┌─────────────────────────────────────┐
│ ‹  Пт 15 авг  ›          Сегодня    │
├─────────────────────────────────────┤
│ Рабочий день          [ Изменить ]  │
│ 10:00 – 19:00                       │
│ Перерыв 13:00–14:00                 │
│                                     │
│ [ + Индив ]  [ + Группа ]           │  ← из свободного слота / sheet
│                                     │
│ 10:00 ████ Мария (индив)            │
│ 11:00 · свободно ·                  │
│ 12:00 · свободно ·                  │
│ 13:00 ░░░░░ перерыв ░░░░░           │
│ 14:00 ████ Группа «Сила» 3/8        │
│ 15:00 · свободно ·                  │
│ …                                   │
└─────────────────────────────────────┘
```

**Изменить** → sheet:

```
┌─────────────────────────────────────┐
│ Расписание дня            [ Готово ]│
├─────────────────────────────────────┤
│ ☐ Выходной (без start/end)          │
│                                     │
│ Начало    [ 10:00 ]                 │
│ Конец     [ 19:00 ]                 │
│                                     │
│ Перерывы                            │
│ 13:00 – 14:00              [ ✕ ]    │
│ [ + Перерыв ]                       │
│                                     │
│ [ Сбросить расписание ]             │  ← disabled, если есть записи
└─────────────────────────────────────┘
```

**Валидация UI:** без start/end нельзя добавить перерыв; перерывы внутри окна, без наложений; нельзя сузить окно так, что занятие окажется снаружи; сброс при записях — нельзя.

## F. Pro · Создать индив из слота

Слоты = та же сетка, что у клиента. Дедлайн самозаписи на тренера **не** действует (можно до старта).

```
┌─────────────────────────────────────┐
│ Новое занятие             [ Отмена ]│
├─────────────────────────────────────┤
│ 15 авг · 11:00 – 12:00              │  ← из слота, длительность из настроек
│                                     │
│ Клиент                              │
│ ┌─────────────────────────────┐     │
│ │ Мария Иванова            ▾  │     │
│ └─────────────────────────────┘     │
│                                     │
│ [ Создать ]                         │
│ Клиенту уйдёт запрос на подтверждение│
└─────────────────────────────────────┘
```

После создания слот **занят** (ожидание подтверждения). Статус на сетке: «ждёт клиента».

Убрать блок **«Мои часы»**.

```
┌─────────────────────────────────────┐
│ Запись клиентов                     │
├─────────────────────────────────────┤
│ Длительность занятия                │
│ ┌─────────────────────────────┐     │
│ │ 60 мин                   ▾  │     │
│ └─────────────────────────────┘     │
│ Для индив и групп                   │
│                                     │
│ Самозапись не позже чем             │
│ ┌─────────────────────────────┐     │
│ │ за 30 минут              ▾  │     │
│ └─────────────────────────────┘     │
│ Варианты: день / 3 ч / 2 ч / 1 ч /  │
│ 30 мин / без ограничения (0)        │
│ «День» = нельзя на сегодня          │
└─────────────────────────────────────┘
```

Точка входа: Профиль / настройки тренера (как принято в T-101 Кабинет).

## H2. Точки входа (IA)

| Что | Где |
|-----|-----|
| Сетка дня / окна | Tab **Расписание** (как T-101) |
| Шаблоны дня + шаблон недели | Кабинет → **Шаблоны расписания** (или подпункт Расписания «⋯ / Настройки дня») |
| Длительность + дедлайн самозаписи | Кабинет → Профиль / настройки тренера (блок «Запись клиентов») |
| «Мои часы» | **Удалить** из профиля |

На дне без расписания CTA «Применить шаблон…» ведут в те же списки шаблонов (экраны B / E).

```
┌─────────────────────────────────────┐
│ Скопировать расписание    [ Отмена ]│
├─────────────────────────────────────┤
│ Откуда                              │
│ ‹  Пн 11 авг  ›                     │  ← date picker; дни с расписанием
│ 10:00–19:00 · перерыв 13–14         │
│                                     │
│ Куда: Пт 15 авг (сейчас пустой)     │
│                                     │
│ [ Скопировать ]                     │
└─────────────────────────────────────┘
```

Только если **куда** без расписания (или после явного сброса, если записей нет). Прошедшее «куда» — нельзя. Снимок, без связи с источником.

## M. Pro · Записать клиента в группу

```
┌─────────────────────────────────────┐
│ Группа «Сила» · 14:00       [ ✕ ]   │
├─────────────────────────────────────┤
│ 3/8 · можно до конца занятия        │
│                                     │
│ Участники                           │
│ · Иван                              │
│ · Мария                             │
│ · …                                 │
│                                     │
│ [ + Записать клиента ]              │
│   → выбор клиента → запрос          │
│     подтверждения клиенту           │
└─────────────────────────────────────┘
```

До ответа место **занято** в ёмкости. Отказ → место свободно + канал тренеру. Автосрока нет. То же правило, если тренер записал клиента на индив (F).

```
┌─────────────────────────────────────┐
│ ‹  Пт 15 авг  ›                     │
│ Тренер: Алексей                     │
├─────────────────────────────────────┤
│ Записаться                          │
│                                     │
│ [ 11:00 ]  [ 12:00 ]  [ 15:00 ]     │
│ [ 16:00 ]  [ 17:00 ]                │
│                                     │
│ Группы в этот день                  │
│ ┌─────────────────────────────┐     │
│ │ Сила · 14:00 · 3/8 свободно │     │
│ │ [ Записаться ]              │     │
│ └─────────────────────────────┘     │
└─────────────────────────────────────┘
```

- Слоты с учётом дедлайна самозаписи; занятые / перерыв / группа — не в списке индив.
- День без расписания / выходной → empty: «В этот день записи нет».
- Тап по слоту → подтверждение «Записаться на 11:00?» → **сразу** в расписании.

## Состояния и ошибки (кратко)

| Кейс | UI |
|------|-----|
| Применить шаблон на день с расписанием | Disabled / «Уже задано» |
| Сузить день поверх записи | Блок сохранения + пояснение |
| Сброс при записях | Кнопка disabled |
| Перерыв вне окна / пересечение | Инлайн-ошибка |
| Слот ушёл (гонка) | Toast + обновить список |
| Группа полная | «Мест нет», без записи |
| Дедлайн самозаписи | Слот не показываем / disabled |
