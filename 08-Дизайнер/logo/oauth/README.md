# OAuth · иконки кнопок VK / Яндекс

Векторные иконки **28×28** для кнопок входа (T-111).

| Файл | Назначение |
|------|------------|
| `icon-vk.svg` | Монограмма VK, `currentColor` (на кнопку `#0077FF` — белый) |
| `icon-vk-color.svg` | Готовый квадрат Azure `#0077FF` + белый глиф |
| `icon-yandex.svg` | Буква «Я», `currentColor` |
| `icon-yandex-color.svg` | Готовый квадрат `#FC3F1D` + белая «Я» |

## Источники

- **VK:** официальный SVG из [пользовательской кнопки VK ID](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/elements/custom-button/custom-button-web). Цвет кнопки Azure `#0077FF` — [требования к дизайну](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/guidelines/design-rules).
- **Яндекс:** глиф «Я» из [Yandex logo 2021 Russian (Wikimedia)](https://commons.wikimedia.org/wiki/File:Yandex_logo_2021_Russian.svg), цвет `#FC3F1D`. Правила: [logotype_rules](https://yandex.com/company/general_info/logotype_rules), кнопки ID: [buttons-design](https://yandex.ru/dev/id/doc/ru/codes/buttons-design).

## Нельзя

- Менять фирменные цвета глифа/кнопки провайдера.
- Искажать пропорции знака.
- Подставлять неофициальные «похожие» иконки с иконок-паков вместо бренд-знака на OAuth-кнопке.
