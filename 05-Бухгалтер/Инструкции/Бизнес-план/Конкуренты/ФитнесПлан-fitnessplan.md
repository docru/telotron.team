## 1) Позиционирование

**Для кого:** **онлайн-тренеры**.

**Оффер:** клиенты, программы, прогресс, чат и оплаты **в одном месте**; замена Google Docs / Excel / WhatsApp / заметок об оплатах.

**Хук:** бесплатно **до 3 клиентов навсегда** (без карты); дальше — платные лимиты. Функции **одинаковые** на всех тарифах.

---

## 2) Функционал (по лендингу)

| Блок | Содержание |
|------|------------|
| **Клиенты** | Профиль: план, последняя тренировка, статус оплаты, история |
| **Программы** | Многонедельные планы, шаблоны, независимая копия на клиента |
| **Выполнение** | Отметки подходов/весов, видео техники, видно «застрял» или нет |
| **Прогресс** | Вес, замеры, фото, личные рекорды |
| **Чат** | 1-на-1 и групповые сообщения рядом с планом |
| **Оплаты** | Учёт тарифов клиента, история, просрочки (**без** приёма денег платформой) |
| **Клиентский UX** | Браузер телефона, без установки; напоминания в **Telegram** (заявлено) |
| **Данные** | Выгрузка / удаление аккаунта |

**Явно нет (FAQ):** учёт питания, интеграция с фитнес-браслетами — «фокус на тренировочном процессе».

## 3) Монетизация

| Тариф | Цена | Лимит клиентов |
|-------|------|----------------|
| Бесплатно | **0 ₽** | до **3** |
| Стандарт | **990 ₽/мес** | до **15** |
| Профи | **2 490 ₽/мес** | до **50** |
| Безлимит | **4 990 ₽/мес** | без ограничений |

- Клиент платформы — **бесплатно** (опц. замеры тела **99 ₽/мес**).
- **Нет комиссии** с оплат клиентов тренера; деньги — напрямую тренеру, в продукте только **учёт**.
- Отмена / смена тарифа в любой момент (заявлено).
- Отдельного «триала» нет: freemium вместо триала.

## 4) Сильные стороны

1. Ближайший **прямой аналог** Telotron по job: «всё в одном для онлайн-тренера».
2. Прозрачная сетка и **низкий вход** (0 ₽ / 3 клиента) — легче Telotron по порогу для T3.
3. Цена **Профи 2 490** vs Telotron **~5 000** — давление на WTP.
4. Честный FAQ: нет питания, нет комиссии, данные можно выгрузить.
5. Конструктор программ + видимость выполнения — то, что спрашивают в интервью (Катя, Павел).

## 5) Слабые / риски

1. **Нет питания** — слабо для гибридов тренер+нутрициолог (ядро T1 Telotron).
2. **Лимит клиентов** на freemium/средних тарифах — у Telotron на Лайте квоты клиентов **нет** (канон).
3. Фокус **только онлайн** — слабее для T2 (зал, запись, группы).
4. Нет нативного приложения (как и Telotron PWA — паритет).
5. Ранний продукт: мало публичных доказательств retention.

## 6) Угроза для Telotron

| Уровень | Почему |
|---------|--------|
| **Высокая** для соло **онлайн**-тренеров (T1) | Тот же narrative «всё в одном»; дешевле |
| **Средняя** для гибрид питание+тренировки | У них нет дневника питания — окно для Telotron |
| **Низкая–средняя** для T2 с залом | Календарь/группы/запись — преимущество Telotron при зрелости M2 |

**Как бить:**

- Не соревноваться только ценой 990 ₽ — бить в **глубину** (питание, календарь, группы, напоминания, локальный контур MAX/TG).
- В КП явно: **Лайт без лимита клиентов** vs их «до 3 бесплатно, дальше плати за слоты».
- Пилотные кейсы «тренер+нутрициолог» против FitnessPlan.
