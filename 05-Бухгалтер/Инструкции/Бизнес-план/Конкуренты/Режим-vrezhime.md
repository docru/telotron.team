## 1) Позиционирование

**Для кого:** тренеры и нутрициологи.

**Оффер:** вести **в 3 раза больше клиентов**, не тонув в переписке. Фокус — **между сессиями**: клиент молчит о срывах → отток; «Режим» показывает «остальные 165 часов» недели.

**Ключевой хук:** дневник питания **голосом** / текстом; AI → КБЖУ; тренер видит **выжимку недели** и **флаги риска оттока**.

## 3) Монетизация

### Канон по продукту (кабинет «Счёт», 2026-07-21)

**Модель:** платит **тренер**; **390 ₽/мес × активный клиент** (seat SaaS).

| Параметр | Значение |
|----------|----------|
| Клиент → платформе | **0 ₽** («не платят нам ничего. Никогда.») |
| Деньги клиента → тренеру | **100%** |
| Активный | Ведёт **дневник питания** (не тренировки/вес) |
| Триал | **5 дней** с первого активного; карта — тогда |
| При 0 активных | **0 ₽** |

**TCO vs Telotron Профи (~5 000):** Режим дешевле при малой базе; ≈ паритет около **13** активных дневника; дальше seats **дороже** фикса.

Скрин: [скрины/Режим/03-счёт-монетизация.png](Обзоры%20приложений/скрины/Режим/03-счёт-монетизация.png).

## 4) Сильные стороны

1. Home-виджеты + список с риском — эталон кабинета нутрициолога.
2. Низкий friction ввода (голос/текст + AI).
3. Карточка без вкладок + AI-выжимка + повестка.
4. Подсказки сообщений клиенту.
5. Money story: клиентские деньги **ваши**; вход без карты.

## 5) Слабые / риски

1. Узкий scope — **только питание** (+ удержание вокруг него).
2. При росте активных дневников цена **линейно** растёт (vs фикс Профи).
3. Нет видимой партнёрки.
4. Ранняя стадия; AI-комплаенс еды.
5. Расхождение лендинг vs кабинет по биллингу — путаница в рынке.

## 6) Угроза для Telotron

| Уровень | Почему |
|---------|--------|
| **Средняя–высокая** для T1 питание/онлайн | Дневник + удержание + дешёвый вход |
| **Низкая** для T2 зал/группы | Другой job |
| **Ценовая** | При 1–10 активных seats часто **дешевле** 5k; при 15+ — наш фикс выгоднее |

**Как бить:** полный день тренера; партнёрка; TCO «13+ дневников → фикс дешевле»; Лайт без квоты; два режима КБЖУ (примерно/точно).
