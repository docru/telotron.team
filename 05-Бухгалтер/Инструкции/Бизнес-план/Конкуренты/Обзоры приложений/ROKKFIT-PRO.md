## Что понравилось (директор)

Приоритет для Telotron — **заимствовать / усилить**, не копировать слепо.

| # | Что | Почему важно | Действие для нас |
|---|-----|--------------|------------------|
| 1 | **Лёгкая регистрация** | Мало трения → выше конверсия | Сравнить с шагами T-066; держать обязательные поля минимальными (у них: ник, имя, телефон, пол + согласие; фамилия и ДР — опционально) |
| 2 | **Главная: всё сразу видно** | Home = карта продукта, не «пустой кабинет» | Пересмотреть home Pro: быстрые действия + сетка модулей (как у них) |
| 3 | **Push в приложении** + типы оповещений | У нас напоминания завязаны на мессенджер | **Ключевой gap:** native/PWA push + категории (сообщения, записи, завершение тренировки, новости, инвайты) |
| 4 | **Оформление бонусной / реферальной** | Понятный раздел «как получить / пригласить / история» | Украсть **UX раздела**, не модель «баллы → мерч» |
| 5 | Календарь (неделя с часами) | Паритет + чуть богаче вид | Сверить с нашим календарём; оценить week+hours |
| 6 | Быстрая тренировка | Низкий friction «просто время + название» | Кандидат в M2 / быстрые действия |
| 7 | Чаты + напоминания + ЧаВо in-app | Один контур без Telegram-зависимости | Чаты — осознанный gap; ЧаВо — дёшево добавить |
| 8 | Секундомер / интервальный таймер | Утилита на зале | Nice-to-have, не ядро |
| 9 | Калькуляторы (BMR) | Доверие «PRO» | Nice-to-have / Макс |
| 10 | Питание на уровне нашего | Паритет по ручному КБЖУ + фото | Не отставать; FatSecret — опционально позже |

## Наблюдения прохода 1 (2026-07-21)

### 1. Регистрация

Экран «Расскажите о себе» ([01-регистрация-профиль.png](скрины/ROKKFIT-PRO/01-регистрация-профиль.png)):

- Обязательные: **никнейм, имя, телефон, пол** + чекбокс Условия / Политика.
- Опциональные: фамилия, дата рождения, фото, email (может быть предзаполнен).
- Вердикт: **очень лёгкая** — нравится.

### 2. Главная

([02-главная.png](скрины/ROKKFIT-PRO/02-главная.png))

- Ближайшие записи + **быстрые действия** (назначить тренировку / создать контакт / напоминание).
- Сетка меню: График, Онлайн ведение, Финансы, Программы, Продукты и блюда, Услуги, Клубы, Продвижение, Чаты, Таймер, Калькуляторы, Напоминания, **Бонусная система**.
- Нижняя навигация: Home · Клиенты · Журнал · Календарь · Меню.
- Вердикт: **главная лучше, чем у Telotron** — сразу вся карта продукта.

### 3. Питание

([03-питание-продукты.png](скрины/ROKKFIT-PRO/03-питание-продукты.png), [04-питание-блюда.png](скрины/ROKKFIT-PRO/04-питание-блюда.png))

- Вкладки Блюда / Продукты; избранное / мои / все.
- Ручной ввод продуктов и КБЖУ; свои продукты и блюда.
- Фото приёма: **до 9** за приём (по словам директора).
- Блюда с рецептами + рейтинг в каталоге.
- Вердикт: **на уровне Telotron**; свои блюда — **сомнительная польза** (каталог рецептов красиво, но не must).

### 4. Календарь

- Практически **один в один** с Telotron.
- Отличие: **неделя с часами** (богаче сетка).

### 5. FatSecret

([07-новости-fatsecret.png](скрины/ROKKFIT-PRO/07-новости-fatsecret.png))

- Анонс в ленте «Новости ROKKFIT»: синхронизация дневника FatSecret; тренер видит приёмы в ежедневных отчётах.
- Плюс для клиента с привычкой FatSecret; у нас такого нет.

### 6. Быстрая тренировка

- Время + название **без деталей** — быстрый слот / факт занятия.
- С главной: «Назначить тренировку».

### 7. Блюда / рецепты

- Каталог + создание своих.
- Директор: польза **сомнительна** (не копировать в MVP ради «как у них»).

### 8. Бонусная система

([05-бонусная-система.png](скрины/ROKKFIT-PRO/05-бонусная-система.png))

- Баллы за реферал: **50** за атлета / **250** за тренера после **30 активных дней**.
- Трата: **в будущем** на мерч и спортпит в **их** магазине — ориентир на **внутренние продажи**, не на скидку абонплаты.
- UX: баланс → «как получить» → пригласить (атлет/тренер) → копировать/поделиться → приглашённые / начисления.
- Вердикт: **модель не наша**, **оформление раздела нравится** → эталон UI для партнёрки Telotron.

### 9. Клиент сам составляет программы

- В экосистеме клиент (ROKKFIT) может вести себя **без тренера**: свои программы и тренировки.
- Следствие: платформа = marketplace + self-serve, не только «кабинет тренера».

### 10–12. Чаты, напоминания, уведомления

([06-чаты.png](скрины/ROKKFIT-PRO/06-чаты.png), [12-настройки-уведомлений.png](скрины/ROKKFIT-PRO/12-настройки-уведомлений.png))

- In-app чаты (новости + поддержка в списке; клиентские диалоги — дальше).
- Напоминания — отдельный модуль.
- **Push в приложении** с категориями:
  - все уведомления (мастер-тогл);
  - сообщения;
  - записи на тренировки/услуги;
  - завершение тренировки клиентом;
  - новости;
  - приглашения.
- Вердикт директора: **у нас для этого нужно подключать мессенджер** — главный функциональный gap на этом проходе.

### 13–15. Таймер, калькуляторы, ЧаВо

([08-таймер-интервалы.png](скрины/ROKKFIT-PRO/08-таймер-интервалы.png), [09-калькуляторы.png](скрины/ROKKFIT-PRO/09-калькуляторы.png), [10-калькулятор-bmr.png](скрины/ROKKFIT-PRO/10-калькулятор-bmr.png), [11-чаво.png](скрины/ROKKFIT-PRO/11-чаво.png))

- Секундомер + интервалы (работа / отдых / раунды / циклы / подготовка, сохранение «мои таймеры»).
- Калькуляторы: пока **BMR** (Маффин–Джеор / Харрис–Бенедикт / Том Венуто).
- ЧаВо с поиском и категориями (общие / занимающиеся).

## Вердикт (проход 1)

**Итог:** ROKKFIT PRO — зрелый native «полный день тренера» с сильной **картой продукта на home**, **in-app push** и реферальным UX. По ядру (календарь, питание) — паритет; по уведомлениям и главной — они впереди.

**Заимствовать в первую очередь:**

1. Структура **главной** (ближайшее + быстрые действия + сетка модулей).
2. **Push + категории уведомлений** без обязательного мессенджера.
3. **UX бонусного/партнёрского раздела** (не модель мерча).
4. Минимальная **регистрация** (уже в духе T-066).
5. Быстрая тренировка (время + название).

**Не копировать в MVP:** каталог блюд «ради красоты», баллы в свой магазин, калькуляторы/таймер как приоритет.

**Чем бить:** прозрачные тарифы, партнёрка в **абонплату**, локальный контур, Лайт без квоты клиентов, честный PWA-старт.

**Приоритет мониторинга:** высокий.

**Открыто на следующих проходах:** тарифы PRO после paywall; онлайн-ведение / финансы / продвижение глубже; сценарий клиент↔тренер end-to-end.
