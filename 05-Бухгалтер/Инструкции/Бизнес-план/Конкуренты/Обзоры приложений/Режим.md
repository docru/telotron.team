## Наблюдения прохода 1

### 1. Главная

([01-главная.png](скрины/Режим/01-главная.png))

- Демо ввода еды: «Скажи или напиши…» + кнопка **Сказать**.
- Карточка AI-помощника: клиент в риске → готовый текст сообщения → **Открыть и отправить**.
- Виджеты: подопечных / активных / **в риске** / **молчат 3+ дн.**
- Заполнение дневника (7 дн.), результаты · вес.
- Список «Подопечные»: фильтры Все / В риске / Молчат / Активны; в строке — теги, sparkline активности, ккал, Δ веса.
- Шапка: **Счёт**, **Пригласить**.

### 2. AI и КБЖУ

Директор: разобрался — **не сложно** сделать. Нужны **2 режима**:

| Режим | Как | Когда |
|-------|-----|-------|
| **Примерно** | ИИ по тексту/голосу (+ уточняющие вопросы от ИИ) | Домашняя еда, кафе, «борщ и котлета» |
| **Точно** | База продуктов + штрихкод + форма веса | Упаковка, контроль |

Связь: [дневник-питания-ии-оценка-кбжу](../../../../../backlog/идеи/дневник-питания-ии-оценка-кбжу.md) · [дневник-питания-штрихкод-кбжу](../../../../../backlog/идеи/дневник-питания-штрихкод-кбжу.md).

### 3. Список клиентов

Информативно (риск, срыв, ккал, вес, активность). Риск **перегруза** — но для привыкшего тренера даёт обзор многих клиентов сразу. У Telotron параметров больше → нужна **иерархия** сигналов, не копировать 1:1.

### 4. Карточка клиента (тренер) — детально

Скрины: [02](скрины/Режим/02-карточка-клиента.png) (пример Марина) · [04–06](скрины/Режим/04-карточка-клиента-план-цели.png) (живой клиент rap694)

**Оценка директора:** нравится, что **всё грамотно, компактно и наглядно** собрано на одном скролле — **без вкладок**.

**Блоки карточки (сверху вниз):**

| Блок | Содержание |
|------|------------|
| Шапка | Аватар, имя, статус «**нужно внимание**» |
| **План питания** | Пол, возраст, рост, вес → цель, активность; **КБЖУ**; «Изменить» |
| **Цель недели** | Текст цели для клиента + чекпоинт в середине недели → «Задать цель недели» |
| **Программа тренировок** | Ссылка (видео/PDF/плейлист) + название → «Прикрепить программу» |
| **Дни тренировок** | пн–вс; напоминание клиенту накануне; 2 пропуска подряд → подсветка в списке |
| **Неделя одним взглядом** | AI-сводка: дни дневника, ккал/цель, белок, тренировки, «обсудить…» |
| **Дневник · 7 дней** | Виджеты: дней, ккал/цель, белок, тренировки, стрик, вес |
| **Сигналы недели** | Теги-алерты (мало дней в дневнике и т.п.) |
| **Повестка на тренировку** | AI: о чём поговорить (напр. «якорь — хотя бы завтрак») |
| **Написать клиенту** | **Черновик голосом ИИ** → текст → «Отправить черновик» |
| **Заметки о клиенте** | Приватно, клиент не видит |

**ИИ в карточке — много рекомендаций.** У Режим это ядро продукта.

**Красная линия Telotron (директор):** софт с **медицинскими / оздоровительными рекомендациями** тянет **лицензирование Минздрава** — **этим путём не идём**.

| У Режим (риск для нас) | Что можно **без** мед. лицензии (подумать позже) |
|------------------------|--------------------------------------------------|
| Повестка «согласуй якорь — завтрак» | Напоминание **записать** дневник / отметить тренировку |
| AI-черновик сообщения с советом по питанию | Черновик **по факту данных** («3 дня молчит», «пропустил 2 тренировки») |
| Разбор недели «обсудить срыв» | **Операционные** сигналы: оплата, запись, дедлайн программы |
| Цели по КБЖУ в UI | Подсказки **по процессу** ведения, не по лечению |

→ Идея на потом: [ai-подсказки-тренеру-граница-медицины](../../../../../backlog/идеи/ai-подсказки-тренеру-граница-медицины.md).

**Для Telotron сейчас:** взять **компоновку карточки** (виджеты, сигналы, один скролл); блоки тренировок/календаря/оплат — свои; AI-слой — только в разрешённом контуре.

### 5. Подсказки к отправке

На главной и в логике «помощник не говорит от имени тренера, но готовит текст» — нравится. Кандидат: черновики касаний при риске / срыве / молчании.

### 6. Партнёрка

В просмотренном UI **не видна**. Окно для Telotron.

### 7. Монетизация — факт из продукта (корректировка!)

([03-счёт-монетизация.png](скрины/Режим/03-счёт-монетизация.png))

**В кабинете сейчас (не revshare с лендинга):**

| Параметр | Факт в UI |
|----------|-----------|
| Кто платит платформе | **Тренер** |
| Клиент → платформе | **«не платят нам ничего. Никогда.»** |
| Деньги клиента → тренеру | **100%** у тренера (цена — сам тренер) |
| Тариф | **390 ₽/мес за каждого активного клиента** |
| Триал | **первые 5 дней бесплатно** (с первого активного) |
| Когда карта | При появлении первого активного клиента |
| Кто «активный» | Кто **ведёт дневник питания**; тренировки/вес **не** считаются |

**Следствие TCO (грубо):**

| Активных (дневник) | Режим | Telotron Профи |
|--------------------|-------|----------------|
| 0 | 0 ₽ | 0 на Лайте / 5k на Профи |
| 5 | **1 950** ₽ | **5 000** |
| 13 | **~5 070** ₽ | **5 000** |
| 20 | **7 800** ₽ | **5 000** |
| 30 | **11 700** ₽ | **5 000** |

Пересечение ~**13 активных** дневника: дальше Режим **дороже** фикса Профи. При малой базе Режим дешевле входа (и без «плачу 5k при 2 клиентах»).

> Ранее по лендингу фиксировали **revshare** (клиент платит через платформу, доля). **В продукте на 2026-07-21 — другая схема:** pay-per-active seat. Лендинг/калькулятор могли устареть или описывать другой контур — **перепроверить лендинг** и обновить канон конкурента.

## Наблюдения прохода 2 · клиентское приложение

### C1. Входная анкета (тренеры просили)

Скрины: [client/01–06](скрины/Режим/client/), [22-профиль](скрины/Режим/client/22-профиль-анкета-норма.png)

**Онбординг после инвайта (пошагово):**

1. Цель: сбросить / держать / набрать + целевой вес
2. Антропометрия: пол, возраст, рост, вес
3. Уровень активности (сидячий → очень высокая)
4. Аллергии и ограничения (свободный текст)
5. **Установка приложения** — сильный copy: «Твой тренер уже ждёт», «записывай еду голосом или текстом», «он видит твой прогресс»

**Профиль (повтор/редактирование):** цель, пол, возраст, рост, вес, целевой вес, активность → расчёт **нормы КБЖУ** (ккал + БЖУ). Кнопка «Сохранить изменения».

**Конtrast:** в профиле также текст «тренер приглядывается к ритму — поделай записи пару недель, **без анкет**» — т.е. часть данных собирают **пассивно из дневника**, но **входная анкета всё равно есть** (директор: тренеры просили).

**Для Telotron:** intake Client — не только медсогласие (T-066), но и **структурированная анкета** для тренера (цели, ограничения, активность).

### C2. Тексты, побуждающие пользоваться приложением

Примеры из UI:

- «Запиши приём — **начни стрик честности**»
- «Цели по калориям появятся, когда тренер задаст план. А пока **записывай еду — он это видит**»
- «Начни с одной фразы — скажи или напиши, что ел, **а я посчитаю** калории и БЖУ»
- «Каждый записанный день — **победа честности**»
- «Разбор недели… **тепло и без осуждения**»
- CTA установки: «Тренер уже ждёт» / «Установить приложение»

**Принцип:** не стыдить за неточность, **хвалить факт записи**, снижать порог («одна фраза», «45 секунд»).

### C3. Активность и трата калорий (MET)

Скрины: [10-добавить-активность](скрины/Режим/client/10-добавить-активность-сетка.png), [11-танцы-met](скрины/Режим/client/11-активность-танцы-met.png), [19-история](скрины/Режим/client/19-история-неделя.png)

- Сетка видов активности (бег, силовая, HIIT, йога, танцы… ~23 типа).
- Выбор **минут** (15/30/45/60/90) → расчёт **«−N ккал»** с пометкой **«оценка по MET»**.
- В истории недели: «**−486 потрачено**» рядом с «155 ккал в день» — **нетто-тенденция**, не лабораторная точность.

**Оценка директора:** нравится — **приблизительно, но показывает тенденцию**. Не конкурирует с трекерами Garmin, но закрывает «я потренировался» без ручного ввода калорий.

### C4. Краткое описание еды и активности

Скрины: [12-одной-строкой](скрины/Режим/client/12-записать-одной-строкой.png), [07–09 главная](скрины/Режим/client/07-главная-сегодня-пусто.png)

**Три пути ввода:**

| Путь | Суть |
|------|------|
| **Одной строкой** | «грудка 150 и рис 100, пробежал 5 км» → кнопка **Распознать** (+ «Сфоткать тарелку») |
| **По приёмам** | Завтрак / обед / ужин / перекус / активность — «пока пусто — добавить?» |
| **Поиск / недавнее / частое** | База продуктов, порции (100 г / порция 300 г), подтверждение КБЖУ |

Подсказки формата: понимают «200», «200 г», «2 яйца», «пол банана», «пробежал 5 км», «силовая 40 минут».

**Ключевая мысль:** помогает **записывать**, пусть не идеально точно — лучше грубая запись, чем молчание.

### C5. Чат = распознавание на бэке

Скрин: [18-чат-распознавание](скрины/Режим/client/18-чат-распознавание.png)

- Вкладка **Чат** (навигация: Сегодня · **Чат** · История · Профиль).
- Бот/помощник: «не нужны таблицы… скажи как прошёл день».
- Клиент пишет: *«Каша с маслом, кофе, йогурт с брусникой. Пробежал 3 км»*.
- Ответ: разбор по позициям (ккал) + бег **−341 ккал**; карточки с ✓ и **«Отменить»** на каждую позицию.
- Поле ввода: «Скажи или напиши, что ел…» + **микрофон**.

**Связка Pro ↔ Client:** тренер видит дневник; клиент не думает про «форму приёма пищи» — **пишет как в мессенджере**.

**Для Telotron:** это сильнее нашего «напоминание в MAX/TG без парсинга». Кандидат: in-app чат Client **или** парсинг ответа на reminder (сложнее в TG).

### Прочее (Client)

- **История / разбор недели:** AI-текст «взгляд тренера», стрик «дней честности», виджеты 1/7 записано, 2 тренировки, −486 потрачено.
- **Профиль:** норма КБЖУ; «скажи вес в чате»; опция **«заходы тренера в Telegram»**; «что тренер обо мне помнит» (AI-память из общения).

## Вердикт (проход 1)

**Итог:** Режим — эталон **кабинета нутрициолога**: home-виджеты, плотная карточка, сигналы риска, AI-выжимка и черновики сообщений. Не конкурент «полному дню» (зал/календарь), но бьёт в питание и удержание. Монетизация в продукте — **seat SaaS 390 ₽**, не take rate; при росте базы дневника дорожает быстрее фикса Профи.

**Заимствовать:**

1. Принцип home Pro: **виджеты важного + ссылки на основное + редкое глубже**.
2. Карточка «сводка без вкладок» + AI-абстракт (адаптировать под мульти-модуль).
3. Фильтры риска / молчания в списке клиентов.
4. Черновики касаний клиенту (Pro).
5. Два режима КБЖУ (примерно / точно) + **«одной строкой»** + **чат-NLU**.
6. **Входная анкета Client** (цели, ограничения, активность) — тренеры просили.
7. **MET-активность** для тенденции, не точности.
8. **Copy** «запиши — это победа», стрик, CTA установки PWA.

**Чем бить:** полный контур; партнёрка; при 15+ активных — **фикс дешевле seats**; Лайт без квоты; тренировки + календарь + группы.

**Приоритет мониторинга:** **очень высокий** (питание + Client UX + seats).
