## Как заполнять

1. Сначала пройти **онбординг** (регистрация тренера / приглашение клиента).
2. Пройти **3–5 сценариев** из чеклиста в файле.
3. Зафиксировать **цены** (стор / кабинет / оферта), если на лендинге не было.
4. В конце — **вердикт vs Telotron** (что копировать / чего избегать / чем бить).

Скриншоты класть рядом: `скрины/<продукт>/` или ссылкой в заметках.
