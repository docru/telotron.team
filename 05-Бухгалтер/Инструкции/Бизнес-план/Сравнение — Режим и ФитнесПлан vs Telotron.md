### Разбор: схема «Режим» vs схема Telotron

> **Важно (2026-07-21):** в кабинете Режим — **не revshare**. Платит тренер: **390 ₽/мес за активного** (активный = ведёт дневник питания). Клиенты платформе **ничего** не платят; 100% их оплат тренеру — у тренера. Старый разбор по лендингу (доля с оплат клиентов) — **архив**; ниже — актуальная модель.

**Режим (UI «Счёт»):** seat SaaS. 5 акт. ≈ 1 950 ₽; ~13 акт. ≈ 5 000 ₽; 20 ≈ 7 800 ₽. Вход без карты; 5 дней free с первого активного.

**Telotron (канон):** фикс абонплаты тренера (Профи ~5 000); клиент free; оплаты клиент→тренер вне платформы; без take rate; партнёрка в абонплату.

| | **Режим (факт UI)** | **Telotron** |
|--|---------------------|--------------|
| Плательщик платформы | Тренер | Тренер |
| Метрика цены | **Активный дневник** × 390 ₽ | Тариф (фикс) |
| Деньги клиента → тренеру | 100% вне их доли | 100% вне платформы |
| Порог входа | 0 ₽ до 1-го активного | Триал 30 дн. → Лайт / Профи |
| При 5 активных дневниках | **~1 950** ₽ | **5 000** на Профи |
| При 20 активных | **~7 800** ₽ | **5 000** |
| Риск для тренера | Линейный рост счёта с базой | Фикс; или сидеть на Лайте |
| Риск для платформы | Мало ведущих дневник → мало MRR | Мало платящих тарифов |

**Вывод для КП:** при старте с малой базой Режим **дешевле входа**; при **~13+** ведущих дневник — аргумент «фикс Профи выгоднее seats». Narrative «клиентские деньги ваши» — **паритет** (оба так говорят); бить полнотой продукта и партнёркой, не только «без комиссии».

## 3. Карта конкуренции (jobs)

```text
                    питание / AI-дневник
                           ▲
                           │
              Режим ●──────┼──────
                           │
   удержание ◄─────────────┼─────────────► программы / выполнение
                           │
         ● ROKKFIT PRO     │
              ● Telotron   │   ● ФитнесПлан
              (полный день)│   (онлайн PT)
                           │
                           ▼
                    календарь / зал / группы
```

- **Режим** занимает верх (питание + churn).
- **ФитнесПлан** — правый край (программы + чат + оплаты-учёт).
- **ROKKFIT PRO** — **центр карты**: пересекается с Telotron почти по всему job; плюс **каталог/визитка** и native apps.
- **Telotron** целится в **центр + низ** (календарь/группы) и **верх** (питание); конкурирует с ROKKFIT «лоб в лоб», с ФитнесПланом — по цене, с Режимом — по модели оплаты.

## 4. Выводы для Telotron

### 4.1. Угрозы

1. **ROKKFIT PRO** — **самый полный прямой аналог**: календарь + программы + питание + запись + чат + финансы + клиентское app; **каталог тренеров** как готовый growth-слой.
2. **ФитнесПлан** — близкий SaaS по офферу «онлайн-тренер» при **более низкой цене** и freemium (но слабее питание и запись).
3. **Режим** — конкурент за **питание + удержание**; дешёвый вход (**390 ₽ × активный дневник**); при **~13+** активных seats дороже фикса Профи.

### 4.2. Окна возможностей

| Окно | Против кого | Что усиливать в КП / продукте |
|------|-------------|-------------------------------|
| Тренировки **+** питание в одном кабинете | ФитнесПлан | Дневник, трекер, файл питания |
| Календарь, запись, группы, офлайн/гибрид | ROKKFIT, ФитнесПлан, Режим | M2, группы на Профи |
| Партнёрка vs каталог маркетплейса | ROKKFIT | Партнёрка + прозрачные тарифы на сайте |
| Без комиссии с клиентских денег | Режим (оба 100% тренеру) | Паритет narrative; бить TCO seats vs фикс + полный контур |
| Без лимита клиентов на нулевом тарифе | ФитнесПлан | Лайт: функции урезаны, **не** слоты клиентов |
| Партнёрка и рост тренера | Оба | Уникальный канал GTM Telotron |

### 4.3. Риски позиционирования

- Не сводить Telotron к «ещё одному конструктору программ» — иначе проигрываем ФитнесПлану по цене.
- Не сводить к «AI-дневнику» — иначе проигрываем Режиму на их поле и теряем T2.
- Держать формулу из [Обзора конкурентов](Обзор%20конкурентов.md): **от цели до факта** — тренировки, питание, прогресс, напоминания, (оплаты) — **без админки клуба**.

### 4.4. Цена (черновик для дискуссии)

| Сегмент | С чем сравнивают | Аргумент Telotron |
|---------|------------------|-------------------|
| Онлайн, ≤15 клиентов | ФитнесПлан 990–2490 | Глубина (питание, календарь) + Лайт без квоты |
| Нутри / гибрид | Режим (комиссия) | Полный контур + свой биллинг без take rate |
| Зал / группы | YCLIENTS + чаты | Единый контур, не «вторая админка» |
