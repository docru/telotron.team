# Опрос пилота · 14 дней · голос каждый день


| Поле          | Значение                                                                                                        |
| ------------- | --------------------------------------------------------------------------------------------------------------- |
| **Статус**    | рабочий сценарий                                                                                                |
| **Аудитория** | тренеры пилота (Pro)                                                                                            |
| **Канал**     | голосовые опросы ([T-098](../../backlog/бэклог/T-098-голосовые-опросы-админка-и-канал.md))                      |
| **Цель**      | Каждый день — вопрос → ответ голосом; к концу волны — картина по **полезности**, **удобству**, **предложениям** |
| **Формат**    | **один** опрос · **14 вопросов** · `ask_after_days` **0…13** · без radio/шкал                                   |


---

## Принцип


| Правило      | Как                                                               |
| ------------ | ----------------------------------------------------------------- |
| Частота      | **каждый день** один вопрос в канал (в выбранное время)           |
| Длина ответа | 15–40 сек; вопрос — одна мысль                                    |
| Три темы     | чередуем: контекст → польза → удобство → польза → … → предложения |
| Пропуск      | ок (см. T-098); в сводке отмечаем                                 |


Итого **14 календарных дней** от старта назначения (день 0 = день старта).

---

## Карточка опроса (Pro / Filament)

**Название:** 14 дней с Telotron  

**Описание:**

> Каждый день — один короткий вопрос в ваш канал. Ответьте голосом (можно текстом), как обычному сообщению.  
> Спросим, помогает ли сервис, удобно ли им пользоваться и чего не хватает.  
> Займёт меньше минуты в день. Можно остановить в любой момент в разделе «Опросы».

**Текст по окончании:**

> Спасибо! 14 дней позади. Ваши ответы помогают делать Телотрон удобнее для тренеров — мы читаем каждое сообщение.

## Вопросы · дни 0–13

Вставить в Filament **по порядку**. `ask_after_days` = номер дня.


| День   | Код | Тема        | Текст вопроса                                                                                             |
| ------ | --- | ----------- | --------------------------------------------------------------------------------------------------------- |
| **0**  | Q01 | Контекст    | Расскажите коротко: онлайн, зал или смешанно ведёте клиентов? Сколько примерно активных сейчас?           |
| **1**  | Q02 | Старт       | Уже открывали Telotron сегодня или вчера? Что успели попробовать первым?                                  |
| **2**  | Q03 | Полезность  | Есть ли уже что-то в приложении, что **реально помогает** в работе? Если да — что именно?                 |
| **3**  | Q04 | Удобство    | Где пока **неудобно или непонятно**? Один пример из сегодняшнего или вчерашнего опыта.                    |
| **4**  | Q05 | Полезность  | Если смотреть на ваших клиентов — что Telotron уже **упростил** или пока не упростил?                     |
| **5**  | Q06 | Удобство    | На телефоне пользоваться комфортно или больше тянет к компьютеру / другому способу? Почему?               |
| **6**  | Q07 | Полезность  | Неделя почти. Насколько сервис **полезен** вам прямо сейчас — своими словами?                             |
| **7**  | Q08 | Удобство    | Когда нужно быстро что-то сделать в приложении — получается **быстро** или часто **тормозите**?           |
| **8**  | Q09 | Предложения | Какой функции или возможности вам **не хватает** в Telotron? Назовите одну — даже если она не срочная. |
| **9**  | Q10 | Полезность  | Какой модуль за эти дни трогали чаще всего — и зачем? Клиенты, календарь, тренировки, питание или другое? |
| **10** | Q11 | Удобство    | Что сильнее всего **раздражает** или отнимает время в интерфейсе? Если ничего — так и скажите.            |
| **11** | Q12 | Полезность  | Если бы завтра Telotron исчез — **насколько** это помешало бы? Коротко почему.                            |
| **12** | Q13 | Удобство    | За две недели стало **удобнее** пользоваться или всё ещё тяжело? Что изменилось в ощущении?               |
| **13** | Q14 | Предложения | Финал: что добавить или изменить **в первую очередь**? Одно-два предложения.                              |

## Карта тем (для чтения ответов)


| Тема                 | Дни / коды                                |
| -------------------- | ----------------------------------------- |
| **Контекст / старт** | 0–1 · Q01–Q02                             |
| **Полезность**       | 2, 4, 6, 9, 11 · Q03, Q05, Q07, Q10, Q12  |
| **Удобство**         | 3, 5, 7, 10, 12 · Q04, Q06, Q08, Q11, Q13 |
| **Предложения**      | 8, 13 · Q09, Q14                          |


Динамика полезности: Q03 → Q07 → Q12.  
Динамика удобства: Q04 → Q08 → Q13.  
Приоритет бэклога: Q09 + Q14 (и спонтанные идеи в других ответах).

**Не смешивать:** в Q01–Q02 «ещё не пользовался» + негатив дальше → «не успел попробовать», не вердикт по продукту.

Сегменты по Q01: **T1** онлайн · **T2** гибрид · **T3** мало клиентов / только регистрация.
