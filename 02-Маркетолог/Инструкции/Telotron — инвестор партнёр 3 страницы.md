# Telotron

**Приложение для персональных фитнес-тренеров и их клиентов**

telotron.ru · июль 2026 · конфиденциально

---

## 1. Зачем это нужно

Персональный тренер ведёт **5–30 клиентов**. Планы в Telegram, запись в голове, еда — в другом чате. Когда клиентов больше, тренер тратит время на **переписку вместо тренировок**.

**Telotron** — **одно рабочее место**: расписание, клиенты, тренировки и дневник питания. Тренер назначает — клиент видит у себя.

---

## 2. Как устроен продукт

Два приложения на телефоне (PWA — **с экрана браузера**, без App Store):

| **Pro — тренер** | **Client — клиент** |
| Календарь, клиенты, тренировки | Записи, дневник еды, замеры |
| Группы, шаблоны | Выполняет назначенную тренировку |

**Платит тренер** (~**5 000 ₽/мес**); клиент **бесплатно**. MVP с **11.06.2026**, пилот — **30 дней без оплаты**.

## 4. Как зарабатываем

### Подписка тренера

| Тариф | Цена | Что даёт |
|-------|------|----------|
| **Лайт** | **0 ₽** | Можно работать, но **урезанный** набор функций |
| **Профи** | **~5 000 ₽/мес** | Полный набор для ведения клиентов |
| **Максимум** | **~10 000 ₽/мес** | Плюс инструменты роста (позже) |

- **30 дней бесплатно** при регистрации, без карты
- С **01.08.2026** — оплата через **ЮKassa**; списание **ежедневно** (цена ÷ 30)
- Нет денег на счёте → **Лайт**, данные сохраняются

### Партнёрская программа (главный канал роста)

Тренер делится **ссылкой** — другой тренер регистрируется. Когда приглашённый **пополняет счёт**, пригласивший получает **процент**:

| Уровень | Доля от пополнения |
|---------|-------------------|
| **L1** (прямой) | **20%** |
| **L2** | **5%** |
| **L3** | **2,5%** |

До суммы своей подписки — **скидка**; свыше — **вывод** после договора. Отдела продаж **нет**: рост = **тренер → тренер** + партнёры.
