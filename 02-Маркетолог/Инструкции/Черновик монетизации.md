# Черновик монетизации Телотрон

**Статус:** канон направления · **DEC-007** (2026-08-16).  
**Снято:** сетка тарифов Лайт / Профи / Максимальный и цены `0` / `5000` / `10 000` ₽/мес как ступени.

**Канон в docs:** [модель-монетизации-платформа](../../../_telotron.ru/docs/Бизнес-требования/00-канон-mvp/модель-монетизации-платформа.md) · [модуль-оплаты-платформа](../../../_telotron.ru/docs/Бизнес-требования/02-модули/billing/модуль-оплаты-платформа.md).

**Исследование альтернатив (не ломает канон):** [исследование-монетизация-и-оплаты](../../backlog/идеи/исследование-монетизация-и-оплаты.md).

**Ограничение по данным:** выборка интервью по-прежнему мала для уверенных цифр ставки клиенто-дня — цифры **не** фиксируем до расчёта при реализации.

**Термины:** плательщик — тренер; см. [Глоссарий](../../01-Директор/Инструкции/1-контекст-и-правила/Глоссарий.md).

---

## 1. Целевая схема (DEC-007)

1. **Основной функционал (ядро)** — плата **за каждый день пользования клиентом** (клиенто-день). Чем больше клиентов тренер ведёт в продукте, тем выше дневная нагрузка на счёт.  
2. **Дополнительный функционал (аддоны)** — отдельно, **по абонплате**. Пример: [E-006 Поиск клиентов](../../backlog/эпики/E-006-crm-тренера.md).  
3. **Тарифов-ступеней нет** — не продаём «Лайт/Профи/Макс» как пакеты функций.  
4. **Студии** как отдельная линейка — по-прежнему **не в фокусе** до масштаба (ориентир 200–500 платящих + ресурс).  
5. **Split** с клиентских оплат — **не планируется** без отдельного решения.  
6. Детали ставки, определения клиенто-дня, триала, поведения при нулевом балансе — **когда приступим к реализации** Commerce под новый канон.

---

## 2. Принципы

- Различать **ядро (клиенто-день)** и **аддоны (абонплата)** — иначе снова получится скрытая «тарифная сетка».  
- Клиент **не платит** платформе за базовый Client.  
- Партнёрка тренер→тренер остаётся; база — фактические оплаты приглашённых (ядро + аддоны — уточнить).  
- Не обещать в маркетинге старые цены ступеней.

---

## 3. Связь с сопровождением

Менеджеров по продажам нет. Аккаунт-менеджеры — не раньше ~500–1000 платящих (бизнес-модель). Модель вознаграждения пересматривается при найме под новую монетизацию.

---

## 4. Вопросы к реализации (не блокируют канон направления)

- Определение клиенто-дня; ставка ₽; минимум/потолок.  
- Триал / промо-период.  
- Недостаток средств: что видит тренер.  
- Упаковка аддонов (цена «Поиска клиентов» и следующих).  
- Юртексты оферты без «тарифов».
