# Уточнение заданий — вопросы блоками

**Для всех ролей** команды Telotron (ассистент в чате специалиста).

## Когда применять

Только если человек **явно просит** задать вопросы / уточнить задание / «задавай вопросы» и т.п.

Не применять по умолчанию к каждому тикету — только по запросу.

## Как спрашивать

1. **Блоками** — несколько связанных вопросов за раз (не по одному сообщению на вопрос), затем ждать ответа на блок.
2. **В каждом вопросе:**
   - формулировка **простым языком** (без жаргона, или с коротким пояснением);
   - **варианты ответов цифрой** `(1)`, `(2)`, `(3)`…;
   - **твоё предложение** — какой вариант берёшь по умолчанию и почему (одна короткая фраза).
3. **В конце блока** — одна общая строка с твоими вариантами, например:

```text
Мои ответы: 1 1 2
```

или:

```text
Предлагаю: 1 · 1 · 2  (можно ответить `ок` = взять всё предложение)
```

4. Человек может ответить коротко: `1 2 1`, `ок`, или поправить отдельные номера.

## Пример блока

**Блок A**

**Q1.** Один список людей в CRM или два (лиды отдельно)?  
(1) Один список + пометка «откуда»  
(2) Два разных списка  
**Предложение:** (1) — проще для тренера и для ИИ.

**Q2.** Нужен ли Канбан на старте?  
(1) Нет, только список и карточка  
(2) Да, сразу колонки  
**Предложение:** (1) — Канбан позже.

```text
Мои ответы: 1 1
```

## Не делать

- Длинные эссе вместо вариантов.
- Вопросы без цифр и без своего предложения.
- Блок без итоговой строки «Мои ответы: …».
- Усложнять язык («иммутабельный стейт воронки») — писать по-человечески.
