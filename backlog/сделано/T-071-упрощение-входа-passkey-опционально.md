## Критерии готовности

- [x] Шаг 3 недоступен без завершённого рег. шага 2.
- [x] Pro: нет «Позже»; **shell кабинета заблокирован** до WebAuthn (`EnsureProRegistrationComplete`).
- [x] После привязки: `passkey_credential_hint` в localStorage.
- [x] Login: Passkey по правилам E-003; иначе SMS OTP.
- [x] **Не более 3** активных ключей (`ProPasskeyCredentialLimiter`).
- [x] Monthly nudge — **только Client (будущее)**; для Pro не делаем.
- [x] Recovery Pro через MAX/TG снят (вход только SMS).
- [x] Feature-тесты: `ProPhoneAuthFlowTest`, `ProRegistrationGuardTest`.
