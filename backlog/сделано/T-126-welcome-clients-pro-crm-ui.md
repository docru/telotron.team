## Контекст

В кабинете Pro раздел **CRM** с подразделами **колбек** и **квиз**: настройки + списки заявок.  
Плюс: задать `nick` (маска/валидация), копировать ссылки, **разовая пригласительная ссылка** с контакта, **перевод чужого существующего User в клиента**.

## Критерии готовности

- [x] Раздел CRM → колбек / квиз (временный, feature-flag ок)
- [x] Ник: UI с подсказкой, маской, валидацией (ADR-007)
- [x] Колбек: текст ответа (дефолт) + список заявок
- [x] Квиз: вопросы (3 шаблона), текст приёма + список заявок
- [x] Копирование URL callback/quiz
- [x] С контакта: создать разовую invite-ссылку → регистрация Client → статус `client` + User
- [x] Явный шаг: перевести существующего (чужого) User в клиента; до `client` не светить клиентские данные
- [x] Тесты: nick, настройки, списки, invite, convert

## Вне scope

- Пуши/email оповещения (позже с ИИ)
- Продуктовый UX «Поиск клиентов» / чат E-010
- Публичные страницы (T-117)
