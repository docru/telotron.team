## UI

| Элемент | Поведение |
|---------|-----------|
| Полоска недели | Пн–Вс; стрелки ±1 нед.; подсветка дней с блюдом или фото; выбранный день |
| Контент | Только **выбранный** `meal_date`; по умолчанию сегодня |
| 4 карточки | Завтрак, обед, ужин, перекус — всегда видны |
| Блюдо | Название + опц. вес (г/мл/шт., default г); голос на блюдо |
| Фото | 1 на слот; камера/галерея; замена |
| Скролл | При открытии «сегодня» — к текущему слоту (эвристика по часам) |
| Очистить приём | Все блюда + фото |

Embedded-режим во вкладке календаря — сохранить (`embedded` prop).
