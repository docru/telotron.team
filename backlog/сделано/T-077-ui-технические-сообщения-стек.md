## Контекст

Единый контур кратких **технических** сообщений (успех операции, ошибка API, системные подсказки) в зонах **Pro** и **Client**.

**Вне scope:** push/in-app Reminders, `TelotronFormErrorAlert` в формах, offline-banner shell, onboarding-bar.

**Зоны:** только **Pro + Client PWA** (не public, не Filament).

---

## Поведение (канон)

| # | Правило |
|---|---------|
| 1 | Блок(и) — **всплывающий стек справа внизу** (над tab bar / safe-area). |
| 2 | **Новое сообщение выше** предыдущего (стек растёт вверх). |
| 3 | Каждое сообщение живёт **15 с**, затем исчезает; оставшиеся **сдвигаются вниз** (плавная анимация — по токенам motion, без перегруза). |
| 4 | У каждого сообщения — **крестик** закрытия (dismiss одного). |
| 5 | Если в стеке **> 1** сообщения — у **верхнего** слева от крестика: мелкий **подчёркнутый курсив** «закрыть все» (dismiss всего стека). |
| 6 | Типы: **`info`** — Pro: синий акцент (`primary`), Client: зелёный (`primary`); **`error`** — красный (`destructive`) в обеих зонах. |
| 7 | Одновременно в стеке — **не больше 5**; при 6-м — удалить **самое старое** (нижнее). |

---

## Реализация

- Pinia `useTechMessagesStore` + composable `useTechMessages()` (`pushInfo`, `pushError`, `dismiss`, `dismissAll`).
- Виджет `TelotronTechMessageStack.vue` в `TelotronAppShell.vue`.
- Стили `telotron-tech-msg-*` в `app.css`; `.telotron-toast` удалён.

### Миграция

| Было | Стало |
|------|--------|
| PWA install toast в pro/client `App.vue` | `pushInfo(..., { id: 'pwa-installed' })` |
| `ClientTrackerHomePage` teleport toast | `pushInfo` |
| `ClientFeedCalendar` timezone toast | `pushInfo({ title, lines })`, id `client-feed-timezone` |
