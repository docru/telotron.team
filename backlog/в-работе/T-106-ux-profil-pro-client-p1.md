Гейт → успех + увод; обычный → stay. Сохранить при правке в sheet анкеты.

### PF-01 · блоки-сводки + sheet — срез 2 ← сейчас

Полный канон: [T-106-zadanie-summary-sheets](../../08-Дизайнер/Инструкции/T-106-zadanie-summary-sheets.md)

Кратко:

- Компактный список блоков с текстом-итогом.  
- Тап (основная зона / ›) → bottom sheet с формой этой темы.  
- Save только в sheet; **убрать** якоря и sticky Save среза 1.  
- Аккаунт read-only; уведомления → `/notification-channels`; Выйти — отдельная кнопка.  
- Анкету не дробить на 4 sheet.

Опционально PF-05 (аватар в шапке) — уже частично в срезе 1; не ломать.
