## 1) Зачем

Тренер не создаёт занятия по одному: задаёт **рабочее время** (+ перерывы). Клиент **сам записывается** в свободный слот. Меньше рутины у тренера, понятная доступность у клиента.

---

## 2) Канон PO (сводка для дизайна)

Часовой пояс для «календарного дня» и дедлайнов: **Europe/Moscow**.

### 2.1) Было → стало

| Сейчас (M2) | Цель |
|-------------|------|
| Тренер создаёт `appointment` → клиент на `bookable` | Тренер задаёт **график дня**; клиент выбирает **свободный слот** → создаётся `appointment` |
| `work_day_*` («Мои часы») = ось UI | Настройку **убрать**. Ось календаря = **реальное** расписание дня; если день **не задан** — ось **08:00–20:00** у всех |

### 2.2) Шаблоны и день

| Сущность | Правило |
|----------|---------|
| **Шаблоны дня** | Список, несколько. Содержимое: start, end, перерывы **или** без start/end = выходной |
| **День** | То же (снимок после шаблона). Без start/end = нет рабочих часов, запись закрыта (**TQ7:** то же, что «выходной»). День **без** строки расписания = то же |
| **Шаблон недели** | **Один** на тренера; **7 встроенных** дней (не ссылки на шаблоны дня) |
| **Перерывы** | Только при заданных start/end; внутри окна; **не накладываются** |
| Шаблон **дня** → день | Сегодня и будущие — да; прошедшие — нет. Пишутся start/end/перерывы |
| Шаблон **недели** → дни | Только с сегодня; только дни **без** уже установленного расписания |
| После применения | Правка дня ок; **связи с шаблоном нет** (снимок) |
| Копирование | Можно скопировать расписание с другого дня |
| День уже с расписанием | Шаблон поверх **нельзя** |
| Есть записи на день | Нельзя сдвинуть график так, что занятие вне окна; **нельзя сбросить** день в «не задано» |

### 2.3) Слоты → занятия (индив и создание группы)

- Длительность **фиксированная**, дефолт **60 мин**, в настройках тренера; **одна** для индив и группы.
- Свободное время для записи: **список окон** (шаг = длительность); при выборе создаётся **занятие** (см. TQ1).
- Сетка: от **start** дня; после перерыва — **с конца перерыва**.
- Буфер между записями **не** нужен (можно встык).
- Индив и группа — только **внутри** start/end и **вне** перерывов.
- Группа **блокирует** окно: индив на это время нельзя.
- Клиент и тренер при создании индив — **одна и та же** сетка окон.
- Горизонт самозаписи вперёд — **без лимита** (где есть расписание и окно доступно).
- Предсозданных пустых «слотов» **нет**; сущность в системе — только **занятие** (индив / группа).

### 2.4) Самозапись индив — дедлайн до старта

| Кто | Правило |
|-----|---------|
| Клиент | Дефолт **30 мин** до старта. Настройка тренера: **день / 3ч / 2ч / 1ч / 30 мин / 0**. «День» = нельзя на **тот же календарный день** (только с завтра) |
| Тренер записывает клиента | Дедлайн **0** (можно до старта) |

Самозапись клиента на индив — **сразу** в расписании (без подтверждения тренера).

### 2.5) Кто создаёт / подтверждения

| Тип | Создание занятия | Запись клиента |
|-----|------------------|----------------|
| Индив | Клиент или тренер | — |
| Группа | Только тренер | Клиент или тренер |

- Тренер записал клиента (индив или место в группе) → нужно **подтверждение клиента** (тот же механизм, что подтверждение выхода в напоминании — TQ4); до ответа место/время **занято**; **напоминания о занятии уже идут** (TQ14); при отказе — освобождение + оповещение тренеру.
- Автодедлайна на подтверждение **нет** (висит, пока отказ / снятие тренером).

### 2.6) Группа: запись и отмена

- Дедлайна самозаписи в группу **по времени нет**; лимит — **ёмкость карточки группы** (как M2, на занятии не переопределяем).
- Запись в группу (клиент или тренер) — можно **после начала**, пока группа **не закончилась** и есть места.

### 2.7) Отмены клиентом

| Что | До какого момента | Оповещение тренеру |
|-----|-------------------|--------------------|
| Индив | До **начала** (настройку «за N часов» **убрать**, TQ12) | По **каналу** |
| Место в группе | Пока группа **не закончилась** | По **каналу** |

### 2.8) Настройки тренера (новые / затронутые)

- Длительность занятия (дефолт 60 мин) — **единственная**; старый порог «мин. 30 мин» убрать (TQ11). Хранение: `trainer_profiles` (TQ9).
- Дедлайн самозаписи индив: день / 3ч / 2ч / 1ч / 30 мин / 0 (дефолт 30 мин) — там же.
- Убрать: «Мои часы» (`work_day_*`) в том же релизе (TQ10).
- TZ расчётов дня/дедлайнов: **Europe/Moscow** (TQ8).

### 2.9) Группы и пол (Client)

- Группа другого пола для клиента выглядит как **занятое** время (не как доступная запись) — TQ16.

### 2.10) Экраны для wireframe (ориентир)

**Pro**

1. Список шаблонов дня + редактирование (start/end/перерывы / выходной).
2. Один шаблон недели (7 дней).
3. День календаря: применить шаблон / копировать / править; ось = расписание или 08:00–20:00.
4. Создание индив/группы из сетки окон; запись клиента → ожидание подтверждения.
5. Настройки: длительность + дедлайн самозаписи; без «Мои часы».

**Client**

1. Календарь / день тренера: свободные окна индив (с учётом дедлайна).
2. Самозапись; запись/отмена в группу (ёмкость).
3. Подтвердить / отклонить запись от тренера.
