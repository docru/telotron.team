## Критерии готовности

- [ ] Пробы `openai-direct` (json_schema, 3 модели КБЖУ, `usage.cost`) — разблокирует часть B [T-135](../бэклог/T-135-e010-общий-ai-слой.md)
- [ ] Промпт `leadgen.morning_brief` v1: вход (кандидаты, цифры воронки, до 10 людей под макросами, стиль из профиля), выход — JSON-схема `{items:[{task_id, order, why}]}`
- [ ] Границы: только продвижение; без медицины и обещаний «N клиентов»; только задачи из кандидатов; макросы не ломать
- [ ] Модель, температура, лимит длины `why`, таймаут — значения для конфига
- [ ] Проверочный набор **20–30** ситуаций (новичок без людей, много заявок, всё просрочено, лёгкий план, нутрициолог…) без реальных ПДн
- [ ] Прогон на stage: доля валидных ответов, доля «по правилам», среднее время, стоимость на бриф
- [ ] Отчёт в `11-AI-инженер/Работа/` + [чеклист перед AI-сервисом](../../11-AI-инженер/Инструкции/Чеклист-перед-AI-сервисом.md)
