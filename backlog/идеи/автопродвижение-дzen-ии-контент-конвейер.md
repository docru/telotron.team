## Суть

**Автоматическое продвижение** через **конвейер контента в Дзене**, где ИИ (агент / LLM + скрипты) помогает:

- заводить и вести канал(ы) Дзен;
- генерировать **поток статей/материалов** по темам (фитнес, онлайн-тренер, питание, сопровождение);
- публиковать по расписанию;
- вести на **telotron.ru** / лендинг / каталог / запись на консультацию.

Не «один пост руками», а **система**: темы → черновики ИИ → правка/модерация → публикация → метрики.

Отличие от [SEO-статей платформы](лидоген-для-тренера-онлайн-мозговой-штурм.md) (4–8 статей/мес вручную): здесь упор на **масштаб и автоматизацию** канала Дzen как источника трафика.

## Зачем / для кого

| Кто | Зачем |
|-----|--------|
| **Telotron (маркетинг)** | Органический трафик и лиды **без** большого paid-бюджета; канал, который крутится регулярно |
| **Тренер на Макс** *(перспектива)* | Инструмент «веди свой Дзен» с помощью ИИ — как часть growth toolkit |
| **PO** | Стыкуется с фокусом [онлайн-сопровождение](фокус-только-онлайн-сопровождение-тренеры-нутрициологи.md) и нелокальным лидогеном |

**Контекст стратегии:** сейчас канон — **ручное** продвижение, paid позже ([Стратегия роста](../../02-Маркетолог/Исследования/Стратегия%20роста%20—%20ручное%20продвижение%202026-2027.md)); Дзен в [фокусе пилота](../../01-Директор/Инструкции/Продвижение%20—%20фокус%20пилот%202026.md) — «позже / партнёры со своих площадок». Эта идея — **когда созреем**: полуавтоматический контур вместо только ручных постов.

## Что показывает референс (dzen.guru)

По лендингу примера (не верифицировали цифры дохода):

| Элемент | Смысл для нас |
|---------|----------------|
| Новый канал Дзен «за минуты» | Низкий порог запуска витрины |
| ИИ пишет **много статей параллельно** | Объём, который руками не тянуть |
| Проверка «без следов ИИ» | Риск модерации / качества — нужна политика |
| Показы на **следующий день** | Быстрый feedback loop vs SEO сайта |
| Ранбук, карта заголовков, «сборщик системы» | Нужны **процесс и шаблоны**, не только «попроси ChatGPT» |

**Не копируем слепо:** чужой курс про заработок на Дзене ≠ наш продукт; берём **механику конвейера** под привлечение тренеров / клиентов в Telotron.

## Черновик механики (для Telotron)

```text
Список тем / кластеров запросов (онлайн-тренер, питание, CRM…)
        ↓
ИИ: заголовки + черновики статей (по ТЗ / ранбуку)
        ↓
Человек: фактчек, правка, CTA (редактор 15–30 мин или выборочно)
        ↓
Публикация в Дзен (канал Telotron и/или тематические)
        ↓
Ссылка на сайт / лендинг / «запись на консультацию»
        ↓
UTM → reg / activated / лид
```

**Два уровня продукта (TBD):**

| Уровень | Кто | Что |
|---------|-----|-----|
| **A. Внутренний маркетинг** | Команда Telotron | Свои каналы Дзен, конвейер для acquisition |
| **B. Инструмент тренера** | Макс | «Помогаем вести Дзен» — темы, черновики, CTA на лендинг тренера |

Сначала логичнее **A**; **B** — если A даёт метрики.

## Гипотеза

Если выстроить **полуавтоматический конвейер** статей в Дзен (ИИ + лёгкая правка + CTA на Telotron), то:

1. трафик и reg тренеров растут **дешевле**, чем через контекст ([оценка paid](оценка-контекстной-рекламы-продвижение-приложения.md));
2. не зависим от того, что тренеры сами пишут ([статьи в библиотеке](учебные-материалы-библиотека-статей-тренера.md));
3. канал дополняет SEO сайта и [маркетплейс курсов](курсы-для-клиентов-продажа-через-тренера.md).

**Как проверить:** 1 канал, 20–30 статей за месяц, UTM; метрики — показы, переходы, reg, CAC vs ручной outreach.

## Риски

| Риск | Митigation |
|------|------------|
| Модерация Дзен / «спам ИИ» | Редполитика, фактчек, не 100% автопост без человека |
| Репутация бренда | Тон «эксперт Telotron», не clickbait с чужими цифрами |
| Юр. / реклама | Маркировка, если материал = реклама сервиса |
| Фокус команды | Не отвлекать от ядра Pro/Client; пилот конвейера — отдельный слот |
| Обещания «миллион с Дзена» | Не строить бизнес-план на чужих кейсах без своих цифр |
