## Суть

У **Режим** в карточке клиента много **AI-рекомендаций**: повестка на тренировку, черновики сообщений, разбор недели, цели по питанию. Это сильный UX, но такой контур ближе к **медицинским/оздоровительным** советам.

**Решение директора:** софт с рекомендациями по здоровью требует **лицензирования Минздрава** — **этим путём не идём**.

**Открыто:** какие подсказки можно давать **без** мед. лицензии — операционные, поведенческие, по процессу ведения, не по лечению.

---

## Красная линия (черновик)

| Не делаем (мед. контур) | Можно обсуждать (не-мед.) |
|-------------------------|---------------------------|
| Советы по рациону / срывам / «лечебным» диетам | «Клиент 3 дня не заполнял дневник» |
| AI «что есть при срыве» | «Пропустил 2 тренировки подряд» |
| Диагностика состояния по данным | Черновик **нейтрального** касания («как дела с записью?») |
| Назначение норм КБЖУ как мед. назначение | Напоминание об **оплате / записи / дедлайне** программы |
| | Сводка **фактов** без предписания («за неделю 1/7 дней в дневнике») |

Точная граница — **с юристом**; не продуктовое решение в одиночку.

---

## Что понравилось у Режим (заимствовать без AI-медицины)

- **Компоновка карточки:** один скролл, виджеты 7 дней, сигналы, блок «написать клиенту», приватные заметки.
- Цель недели, дни тренировок, ссылка на программу — **инструменты тренера**, не AI.
