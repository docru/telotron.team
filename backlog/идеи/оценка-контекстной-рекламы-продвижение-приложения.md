## Суть

**Контекстная реклама** для Telotron — платное размещение в поиске и рекламных сетях (Яндекс Директ, VK Реклама и др.), когда пользователь уже ищет или читает тематику: «CRM для тренера», «приложение для фитнес-тренера», «дневник питания клиента» и т.п.

**Цель оценки:** понять, можно ли масштабировать регистрации **дешевле или предсказуемее**, чем только ручными каналами (связи, VK, партнёрка), и **окупается ли** trial → paid при нашем LTV.

---

## Когда имеет смысл даже думать о тесте

| Предусловие | Зачем |
|-------------|--------|
| **Стабильная воронка reg → activated → trial → paid** | Иначе реклама льёт в дырявое ведро |
| **Измеримость:** UTM, события reg/activation, CRM | Без атрибуции нельзя считать CAC |
| **Посадочная / one-pager** под холодный трафик | Не вести на «голый» login |
| **База для сравнения** из органики | CAC paid сравниваем с CAC ручного канала |
| **Бюджет на эксперимент** без угрозы runway | Ориентир: **50–150k ₽** на 4–8 недель теста, не «сразу миллион» |

**Канон сейчас:** paid **не раньше** ~50–100 платников; полноценный тест — ближе к **~200 платников** и разогнанному ручному каналу.

## Что именно оцениваем

### 1. Воронка (обязательные метрики)

```text
Показ → клик (CTR) → визит LP → reg → activated → trial start → paid (30d / 90d)
```

| Метрика | Что значит | Где смотреть |
|---------|------------|--------------|
| **CTR** | Релевантность креатива и запроса | Кабинет Директ/VK |
| **CPC** | Цена клика | Кабинет |
| **CPL / CPReg** | Стоимость регистрации | Реклама ÷ reg с UTM |
| **CPActivated** | Стоимость «живого» тренера | ÷ activated (критерий — как в пилоте) |
| **CAC (paid)** | Стоимость платника | ÷ paid за окно атрибуции |
| **Trial → paid %** | Качество трафика | CRM / billing |
| **Payback** | За сколько месяцев CAC отбивается | CAC ÷ (ARPU × gross margin) |

**North star для решения «масштабировать / нет»:** **CAC < LTV × целевой коэффициент** (ориентир SaaS: payback **≤ 12 мес** при ARPU ~5 000 ₽).

### 2. Качество, не только объём

Реклама может давать дешёвый reg и дорогой мусор. Обязательно срезать:

- **Activated rate** (reg → activated) по каналу
- **Retention D7 / D30** (хотя бы proxy: «открывал Pro N раз»)
- **Trial → paid** vs органика
- **Churn 1–3 мес** у когорт с paid (когда наберётся)

**Красный флаг:** дешёвый CPReg, но **в 2+ раза хуже** trial→paid — канал «покупает формы», не тренеров.

### 3. Юнит-экономика одного эксперимента

Минимальная таблица (заполнять еженедельно):

| Показатель | Формула / источник |
|------------|-------------------|
| Spend | Кабинет рекламы |
| Reg | UTM `source=ydirect` / `vk` |
| Activated | CRM, тот же UTM |
| Paid (30d) | Billing |
| **CAC** | Spend ÷ Paid |
| **CPReg** | Spend ÷ Reg |
| **ARPU** | MRR / платники (средний тариф) |
| **Payback (мес)** | CAC ÷ ARPU |

**Пример sanity-check** (цифры черновые):

- CPC 80 ₽, CR visit→reg 8% → **~1 000 ₽ / reg**
- Reg→paid 5% → **~20 000 ₽ / платник**
- При ARPU 5 000 ₽/мес и churn 5%/мес → LTV порядка **~100k ₽** → **теоретически** может сходиться, но только после факта по **activated** и **retention**, не по reg.

## Каналы и что тестировать первым

| Канал | Формат | Плюс | Риск |
|-------|--------|------|------|
| **Яндекс Директ · поиск** | Запросы «crm тренера», «приложение для тренера» | Высокий intent | Дорогой CPC, мало объёма |
| **Яндекс · РСЯ** | Тематические площадки | Объём | Ниже intent, нужен жёсткий таргет |
| **VK Реклама** | Интересы + сообщества фитнес/тренеры | Аудитория тренеров | Холоднее поиска |
| **Telegram Ads** | Каналы про фитнес/бизнес тренера | Нативность | Мало кейсов, модерация |

**Порядок теста (гипотеза):** сначала **поиск Директ** (узкий intent) → потом **VK** (масштаб) → РСЯ только если поиск сходится.

**Не смешивать** в одной кампании: разные UTM, разные креативы, разные LP при необходимости.

## Дизайн пилотного эксперимента (когда дойдём)

| Параметр | Рекомендация |
|----------|--------------|
| **Длительность** | 4–8 недель |
| **Бюджет** | 50–150k ₽ (достаточно для ~500–1500 кликов на поиске) |
| **Гeo** | 1–2 города или вся РФ — **один** выбор на тест |
| **Посадочная** | Отдельная LP под рекламу: оффер, скрины, CTA reg, без лишнего |
| **UTM** | `utm_source`, `utm_medium=cpc`, `utm_campaign`, `utm_content` (креатив) |
| **Креативы** | 2–3 угла: «всё в одном», «клиенты + питание», «экономия времени» |
| **Стоп-правила** | CPReg > X после 100 кликов → пауза; CAC > 2× органики → стоп |

**Контроль:** параллельно не менять органику и партнёрку; сравнивать когорты **неделя к неделе**.

## Чеклист готовности к paid (до траты денег)

- [ ] Есть **LP** под холодный трафик (не только PWA login)
- [ ] **UTM** доходят до reg в БД / CRM
- [ ] Определён **activated** (тот же критерий, что в [маркетинг-лестнице](../../01-Директор/Инструкции/Цели%20этапов%202026.md))
- [ ] Посчитан **CAC органики** (хотя бы порядок: часы × ставка ÷ paid)
- [ ] Есть **trial→paid %** на 30+ днях наблюдения
- [ ] Юрист: **маркировка рекламы**, ERIR, политика ПДн на LP
- [ ] Креативы и тексты — без медицинских обещаний ([AI / Минздрав](ai-подсказки-тренеру-граница-медицины.md) — отдельно)

## Как сравнивать с ручным продвижением

| | **Ручное (сейчас)** | **Контекст (потом)** |
|--|---------------------|----------------------|
| **CAC** | Низкий денежный, высокий по времени | Предсказуемый ₽, масштабируется |
| **Качество** | Выше (знакомый, vouch) | Ниже на старте — нужен фильтр activated |
| **Скорость** | Медленно | Быстро при бюджете |
| **Потолок** | Capacity основателя | Бюджет + CR |

**Вывод для стратегии:** paid имеет смысл, когда **ручной канал упёрся в capacity**, а **unit-эconomics продукта** уже доказана — иначе масштабируем убыток.
