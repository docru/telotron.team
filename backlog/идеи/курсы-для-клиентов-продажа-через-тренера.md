## Суть

**Готовые учебные курсы** (программы / модули), которые тренер **продвигает клиенту** с **минимальным своим участием**: клиент проходит курс в Client, оплачивает; тренер получает **долю / вознаграждение** за то, что привёл человека на курс и «провёл» его через воронку курса.

Это не замена персональному сопровождению 1:1, а **продуктовый слой**: масштабируемый оффер «курс» рядом с обычной работой тренера.

**Публичный слой:** в **публичной части сайта** (не только внутри Pro/Client) — **маркетплейс курсов тренеров**: индексируемые страницы курсов → **SEO для telotron.ru** + вход холодного трафика → покупка курса и/или **продажа лида тренеру**.

## Зачем / для кого

| Кто | Зачем |
|-----|--------|
| **Тренер** | Деньги с продвижения без полной загрузки временем на каждого клиента; лёгкий upsell / входной продукт; **лиды с витрины курсов** |
| **Клиент** | Структурированный курс (питание / старт / техника / привычки) в том же приложении, где тренер; находит курс через поиск/каталог на сайте |
| **Платформа** | `client_money` + **лидоген**; контент как актив; **органический SEO** (много посадочных под запросы «курс … / программа …»); рост ARPU тренера без роста его часов |
| **PO** | Столп «привлечение / автоматизация» из [УТП](утп-и-картина-развития-продукта.md) в конкретной упаковке |

## Механика (черновик)

```text
Каталог курсов (платформа и/или шаблоны)
        ↓
Тренер выбирает курс → получает ссылку / карточку «предложить клиенту»
        ↓
Клиент покупает / стартует курс в Client
        ↓
Клиент проходит модули (контент, задания, чекпоинты)
        ↓
Тренер видит прогресс (опционально лёгкий check-in)
        ↓
Выплата тренеру: % от оплаты курса или фикс за старт / за завершение
```

| Элемент | Вариант A (платформенный курс) | Вариант B (курс тренера) |
|---------|--------------------------------|---------------------------|
| **Автор контента** | Telotron / партнёры-эксперты | Тренер (или шаблон + правка) |
| **Effort тренера** | Почти только промо + опциональный контроль | Один раз собрать → дальше продаёт |
| **Деньги тренеру** | Revshare / affiliate за продажу и/или completion | Почти вся цена минус take rate платформы |
| **Риск качества** | Контроль платформы | Разброс качества |

**Гипотеза продукта для пилота идеи:** сначала **вариант A** (готовые курсы + промо тренером) — именно «минимальный effort»; вариант B — позже как конструктор.

### Что получает тренер «с минимальным effort»

- Выбрать курс из каталога.
- Отправить клиенту / опубликовать на лендинге / в шаринге.
- (Опционально) видеть, кто купил, кто застрял на модуле — без ежедневного ведения.
- Получать **деньги за продвижение человека через курс** (старт / оплата / завершение — TBD).

### Что не входит (чтобы не размыть смысл)

- Полноценный 1:1 коучинг внутри каждого модуля «обязательно отвечать».
- Замена персональной программы питания/тренировок для VIP-клиентов.
- Мед. рекомендации и «лечение» через курс ([граница Минздрава](ai-подсказки-тренеру-граница-медицины.md)).

## Публичный маркетплейс курсов (SEO + лиды)

Рядом с [публичным каталогом тренеров](публичный-каталог-тренеров-запись-лиды.md): не только «найти тренера», но и **«найти / купить курс»** на публичном домене.

```text
Поиск Google/Яндекс → страница курса на telotron.ru (SEO)
        ↓
Карточка курса: описание, автор-тренер, цена, отзывы, CTA
        ↓
        ├─→ Купить курс → Client / оплата → take rate / payout тренеру
        └─→ «Хочу к этому тренеру» / заявка → лид тренеру (CPL/CPA / пакет тарифа)
```

| Слой | Что даёт |
|------|----------|
| **Витрина** | Каталог + карточки курсов в **публичной зоне** сайта (HTML, индексируемые URL) |
| **SEO** | Много посадочных: тема курса, город/формат, имя тренера → органический трафик на бренд Telotron без paid |
| **Продажа курса** | Клиент платит за курс → деньги тренеру / платформе (как в механике выше) |
| **Продажа лида** | Клиент оставил заявку / интерес к автору курса / «записаться к тренеру» → тренер платит платформе за лид (или лиды в пакете **Макс**) |

**Связка с лидогеном:** курс = **контентный крючок** (ниже friction, чем сразу «купить сопровождение»). Холодный трафик сначала на курс → часть конвертится в **платного клиента тренера** → платформа монетизирует и курс, и лид.

**Отличие от каталога тренеров:** каталог продаёт *человека*; маркетплейс курсов продаёт *продукт* и попутно приводит к тренеру. Можно жить параллельно (курс ↔ профиль тренера ↔ запись).

**Условия смысла:** критическая масса курсов/тренеров + нормальные публичные страницы (title, H1, уникальный текст, без тонкого SEO-спама). Иначе витрина не даст SEO и не окупит лидоген.

## Монетизация (оси)

См. [исследование-монетизация §2](исследование-монетизация-и-оплаты.md).

| Ось | Черновик |
|-----|----------|
| **payer** | Клиент платит за курс; **тренер** платит за лид с витрины (второй поток) |
| **charge_object** | Доступ к курсу / пакету модулей; отдельно — **лид** (заявка / интерес / запись) |
| **client_money** | Да — деньги клиента за курс через платформу (нужны оплаты клиент→… и чеки) |
| **partner / affiliate** | Тренер = промоутер своих/платформенных курсов: % или фикс с продажи / completion |
| **leadgen** | Платформа → тренер: CPL/CPA с публичной карточки курса (как в [каталоге](публичный-каталог-тренеров-запись-лиды.md)) |
| **entitlement** | Доступ Client к курсу на N дней / до завершения |

**Пример цифр (не канон):** курс 3 000 ₽ → тренер 50–70% при платформенном контенте **или** 80–90% при своём контенте; платформа — остаток + эквайринг.  
**Лид:** отдельно, напр. фикс за квалифицированную заявку с карточки курса — TBD.

## Гипотеза

Если тренер может **в 2 клика** предложить клиенту готовый курс и получать **долю с продажи/прохождения**, а курсы ещё и **висят в публичном маркетплейсе**, то:

1. растёт доход тренера **без пропорционального роста часов**;
2. появляется входной продукт дешевле полного сопровождения;
3. клиенты чаще остаются в контуре Telotron (курс → дальше персональный тренер);
4. сайт набирает **органический трафик (SEO)** за счёт карточек курсов;
5. платформа дополнительно зарабатывает на **продаже лидов** с этих страниц.

**Как проверить:** 1–2 пилотных курса + 5–10 тренеров; метрики — # предложений, CR в оплату, completion rate, payout тренеру, NPS клиента, «хочу ещё курс / хочу 1:1»; для публичной витрины — индексирование, organic visits, CR в покупку/заявку, # проданных лидов.

## Открытые вопросы

- [ ] Курсы **только от платформы**, только от тренера, или гибрид (шаблон + бренд тренера)?
- [ ] Триггер выплаты: **оплата**, **старт**, **завершение N%**, или микс?
- [ ] Курс = отдельный SKU или «пакет программ» на базе уже существующих тренировок/питания?
- [ ] Обязателен ли «лёгкий check-in» тренера (раз в неделю) или fully self-serve?
- [ ] Конфликт с абонплатой: курс на **Лайте** или только **Профи/Макс**?
- [ ] Антифрод: тренер «покупает» сам себе / фиктивные completions.
- [ ] Кто отвечает за качество и поддержку клиента по содержанию курса?
- [ ] Публичный маркетплейс: модерация карточек, обязательные поля для SEO, noindex для черновиков?
- [ ] Лид с карточки курса: что считается квалифицированным (заявка / покупка курса / запрос 1:1)?
- [ ] Цена лида vs «входит в Макс»; не дублировать оплату, если клиент уже купил курс у этого тренера.
- [ ] Канонические URL: `/courses/...` vs привязка к профилю тренера; конфликт с лендингом Макс.
