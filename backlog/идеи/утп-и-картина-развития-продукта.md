## Суть

Единая формулировка **УТП Telotron** по пяти столпам и снимок **что уже есть / чего ещё нет**. Документ — точка опоры для приоритизации и монетизации (что продаём на Лайт / Профи / Макс).

---

## УТП (пять столпов)

### 1. Прозрачность взаимодействия тренер ↔ клиент

| Элемент | Смысл |
|---------|--------|
| Карточка клиента | Агрегация данных — сразу видна картина по клиенту |
| Назначение программ | Питание и тренировки |
| Чат | Переписка в контуре продукта |

### 2. Автоматизация рутины

| Элемент | Смысл |
|---------|--------|
| Расписание | Календарь / занятия |
| Оповещения и напоминания | Дисциплина без ручного пинга |
| Запись клиентом | Клиент сам записывается на занятия |
| ИИ: упрощение записи | Питание и тренировки — низкий friction ввода у клиента |
| Приём платежей от клиентов | Деньги клиент→тренер через платформу (или учёт → эквайринг) |
| Чеки клиенту | Автоматическая выдача |
| Налоговая | Подача информации о платеже (НПД / контур) |

### 3. Удержание клиентов

| Элемент | Смысл |
|---------|--------|
| Наглядность прогресса | Мотивация фактом результата |
| Система скидок для удержания | Офферы / условия удержания |
| CRM «старых» | Возврат ушедших / спящих |
| ИИ: прогноз оттока | Сигнал «скоро отпадёт» |
| ИИ: рекомендации по удержанию | Что сделать тренеру *(граница Минздрава — не мед. советы; см. [ai-подсказки](ai-подсказки-тренеру-граница-медицины.md))* |

### 4. Привлечение клиентов

| Элемент | Смысл |
|---------|--------|
| Бонусы за приведение клиента | Реферал клиент→клиент / тренер |
| Лендинг с записью | Публичная витрина + запись |
| VK · запись со стены | Mini App / вкладка |
| ИИ: рекомендации по привлечению | Подсказки роста |
| Услуги по продвижению | Платные / партнёрские услуги платформы |

### 5. Инструментарий удалённой работы (расширение рынка)

| Элемент | Смысл |
|---------|--------|
| Чат | Дистанционное сопровождение |
| Видеозвонки | Сессии без зала |

## Гипотеза

Если держать развитие вокруг пяти столпов и явно показывать «уже есть / будет», проще (1) не расползаться по чужим полям (мед. ИИ, админка клуба), (2) стыковать тарифы с ценностью, (3) бить конкурентов точечно (Режим — питание+удержание; ФитнесПлан — программы+учёт; ROKKFIT — полный native).
