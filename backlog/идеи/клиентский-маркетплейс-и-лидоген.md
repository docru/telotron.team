## Суть

Сейчас ядро Telotron — **тренер приглашает клиента**. Идея: открыть вход **любому клиенту** (self-serve), дать ему выбирать тренеров, и монетизировать **привлечение** для тренера.

| Слой | Механика (черновик) |
|------|---------------------|
| **Клиент без тренера** | Регистрация в Client; дневник / программы по желанию (как у ROKKFIT self-serve) |
| **Выбор тренера** | Каталог / витрина / поиск → заявка / запись |
| **Партнёрка среди клиентов** | Клиент зовёт клиента → бонус (скидка / баллы / период) — *если* клиент платит платформе |
| **Лидоген для тренера** | Платформа приводит клиента → тренер платит **за лид / за старт сопровождения** (не take rate с его оборота с клиентом) |

Отличие от текущей партнёрки: сейчас **тренер→тренер** (скидка абонплаты). Здесь — **платформа→тренер** (плата за привлечённого) и опционально **клиент→клиент**.

---

## Зачем

- Рост базы клиентов без ожидания, что каждый тренер сам приведёт всех.
- Аргумент против ROKKFIT: у них каталог + бонусы в **их** магазин; у нас — деньги/ценность тренеру и клиенту в **рабочем** контуре.
- Совместимо с Макс / каталогом / лендингом тренера.
