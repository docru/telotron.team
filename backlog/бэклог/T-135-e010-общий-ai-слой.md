## Контекст

Клиент Caila живёт в `Modules/Nutrition` и не умеет tools / `json_schema` / учёт стоимости. Для ИИ-консультанта нужен общий слой; второй копии клиента не делаем. Канон — ADR-010.

## Часть A · слой (не ждёт проб)

- [x] `app/Modules/Ai`: `AiChatClient` (`chat`, `chatParallel`), `AiChatRequest`, `AiChatResult` по ADR-010 §2
- [x] Шлюз `adapters/openai-direct`, полный model id; `config/ai.php` (`CAILA_API_KEY`, `CAILA_DIRECT_BASE_URL`, `enabled`, таймаут, необязательный `base_url` на модель)
- [x] `responseFormat`: `text` · `json_object` · `json_schema`; `tools` / `toolChoice` → `toolCalls` в ответе (без цикла исполнения)
- [x] `usage`: токены + `cost_rub` (из Caila, иначе по `price_rub_per_m` модели)
- [x] Таблица `ai_runs` (ADR-010 §4); запись на каждый вызов; ключ API — никогда в журнал и `Log`
- [x] Команда по расписанию `ai:purge-runs` (03:30): через 30 дней обнулить `request_masked` / `response_masked`, через 1 год удалить строки
- [x] `ai.enabled=false` → `error=disabled` без HTTP
- [x] Ретраев по умолчанию нет; опция `retryOnce` (timeout / connection / 5xx)
- [x] Feature-тесты на `Http::fake` (16): успех, JSON schema, tool calls, таймаут, http-ошибка, disabled, запись `ai_runs`, очистка по сроку
