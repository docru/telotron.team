## Контекст

Админ ведёт **опросы** в Filament. Тренер в Pro видит раздел **«Опросы»**: список, старт участия, статус, остановка, смена времени. Вопросы уходят в выбранный канал по `ask_after_days` + **времени суток**; ответы (**голос или текст**) пересылаются **главному партнёру** в MAX.

**Не путать** с идеей [модуль-встроенные-опросы-формы](../идеи/модуль-встроенные-опросы-формы.md) (in-app Forms-like).

### Filament

1. **Список опросов**
2. **Редактирование опроса:** название; список вопросов; **текст по окончании**; переключатель **«Активен»** (дефолт выкл.)
3. **Редактирование вопроса:** текст (textarea); `ask_after_days`
4. **Запуск / участники:** список назначений (старт, отвечено/пропущено, завершён / в процессе / отказ); **назначить** тренерам (мульти → отдельная запись; канал + время, дефолт 19:00) **и** мониторинг самостартов из Pro.

### Pro · раздел «Опросы» (Q10–Q13)

- Пункт в навигации / «Ещё»: **«Опросы»**.
- **Каталог активных опросов** (`is_active = true`) + свои назначения (статус прохождения).
- **Принять участие / запуск** по опросу из каталога:
  1. Проверка: есть ли **хотя бы один** привязанный канал оповещения.
  2. Если **нет** — оповещение + **ссылка** на раздел подключения каналов.
  3. Если **есть** — пользователь выбирает **канал** и **время** прихода вопросов → старт назначения.
- В списке: **остановить** опрос (вопросы больше не уходят).
- Для идущего опроса: можно **изменить время** прихода следующих вопросов.

**Пути старта (Q15–Q16):** основной — тренер сам из каталога; запасной — админ назначает → **сразу старт** (канал и время задаёт админ).

### Активность опроса (Q13)

В Filament у опроса — переключатель / кнопка **«Активен»**.

- В каталоге Pro видны только **активные** опросы.
- **По умолчанию** новый опрос **неактивен**.
- Назначения, уже запущенные, от выключения активности **не отменяются автоматически** (пока не решит PO иначе) — в каталоге просто нельзя **начать новый**.
- **Повтор (Q14):** у пользователя не больше **одного** назначения на данный опрос (после старта/завершения/отказа — снова начать нельзя).

### Расписание вопросов (Q1 + Q2)

У **каждого вопроса** `ask_after_days` (целое ≥ 0) — дней после **даты старта назначения**.

- Дефолт нового вопроса = `max(ask_after_days)` в опросе **+ 1** (пусто → **0**).
- В одном опросе `ask_after_days` **уникален**.

### Время прихода (Q10)

У назначения — время суток (локальная TZ пользователя), когда слать вопрос в день `ask_after_days`.

| Кто | Поведение |
|-----|-----------|
| Пользователь при старте в Pro | Сам выбирает время |
| Пользователь в процессе | Может **сменить** время (влияет на ещё не отправленные) |
| Админ при назначении | Задаёт время; **по умолчанию 19:00** |

### Пропуск (Q4 + Q5)

Отправлен, но **нет ответа** до отправки **следующего** вопроса.

**Последний вопрос:** пропуск в **конце суток** дня отправки (TZ пользователя).

### Текст по окончании (Q12)

Поле у опроса: сообщение в канал, когда назначение **завершено** (все вопросы с ответом или пропуском).

**Дефолт (если админ не менял):**

> Спасибо! Опрос завершён. Ваши ответы помогают нам делать Телотрон удобнее для пользователей — мы читаем каждое сообщение.

### Копирайт и подсказки (Q18)

**Карточка / описание опроса в Pro** (перед стартом) — показать:

- сколько **вопросов** в опросе;
- сколько **дней** длится опрос — **авто**: `max(ask_after_days) + 1` (Q19);
- что отвечать нужно **голосом** (в канале также принимается текст — Q8; в UI акцент на голос);
- фраза: *«У вас это займёт не более 5 мин каждый день»*.

**При старте в Pro** — сообщение, **когда придёт первый вопрос** (дата + время назначения).

**Первое сообщение-вопрос в канале** — короткая инструкция: достаточно **надиктовать** ответ на вопрос (голосом).

**Каждое сообщение с вопросом** — нумерация вида: *«Вопрос 5 из 15»* (+ текст вопроса).

**После принятого ответа** в канал:

- если есть следующий вопрос — **дата** (и время) следующего;
- если вопросов больше нет — сообщение об окончании с благодарностью (поле опроса / дефолт Q12).

### Правки опроса при живых назначениях (Q17)

Менять вопросы можно; изменения действуют только на **ещё не отправленные** слоты назначения.
