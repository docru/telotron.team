## Контекст

Раздел «Назначенные тренировки» в карточке клиента.

## Поведение

| Действие | Правило |
|----------|---------|
| +Добавить | Шаблон → черновик на сервере → форма |
| Назначить | `draft` → `active` |
| В архив | `active` → `archived` |
| Копия | Из active/archived → новый `draft` |
| Редактирование | Только `draft` |
| Удаление | Только `draft` |
| Список | Фильтры; пагинация **20**; пиктограммы действий |

Несколько **active** на пару — без лимита. Копия из шаблона — полный снимок.

## Критерии готовности

- [ ] Все переходы статусов только вперёд
- [ ] Страница просмотра назначения (все статусы)
- [ ] Форма редактирования черновика
