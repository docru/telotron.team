## Контекст

**Безголовая CRM** (E-006): домен + API. Потребители: **E-008**, **E-010**, тонкий Pro UI.  
Не цель этого тикета: помощник, страница записи, каналы (см. E-008…E-010).

Формат: **блоки вопросов** — варианты цифрой + предложение ассистента; ответ строкой вроде `1 1 2` или `ок` (= взять предложения блока).

## Канон (сводка)

| Тема | Решение |
|------|---------|
| Архитектура | Headless: один домен CRM; UI — тонкий клиент *(зафиксировано)* |
| Сущность | **Один список** в CRM + привязка к «Клиентам» в приложении (не две сущности CRM) |
| Статусы | **Новый → В работе → Клиент → Бывший** \| **Отказ** |
| M1 | Связь с приложением; дедуп по телефону; повторный лид → **автосклейка** + история |
| API | Одна внутренняя логика; форма и ИИ пишут через сервер |
| События для ИИ | новый · этап · заметка · следующее действие |
| Заметки | Лента заметок (тренер / ИИ) + «что сделать дальше» (дата + текст) |
| Доступ | Тренер и ИИ — только люди этого тренера |
| Pro UI | **Временно** для отладки MVP; потом ведение **только через ИИ** (E-010) |
