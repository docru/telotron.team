## Контекст

Эпик [E-006](../эпики/E-006-crm-тренера.md): раздел Pro **«Поиск клиентов»** — помощник в центре, не CRM на виду.  
Канон продукта: [описание сервиса](../эпики/E-006-описание-сервиса.md), приоритеты: [инструменты P0–P3](../эпики/E-006-инструменты-приоритеты.md).

Discovery закрывает **границы модуля**, SKU аддона (черновик), ADR сущностей и **матрицу экранов** для wireframe и dev.

## Критерии готовности

- [ ] **Brief / JTBD:** один геройский сценарий «7 дней → первая заявка или касания базы» (см. описание §7 дней)
- [ ] **ADR LeadGen:** границы `Lead` / `ReactivationContact` / `GrowthProfile` vs Client M1, Scheduling M2, Commerce; публичный контур страницы записи
- [ ] **Матрица экранов Pro:** shell, профиль, база, задачи дня, тексты, совещание (черновик); что **не** показываем (воронка, CRM)
- [ ] **SKU аддона (черновик):** связь с [E-001](../эпики/E-001-commerce-модуль.md), DEC-007; trial? — для PO
- [ ] **Юр. чеклист v0.1:** ПДн «бывших» клиентов → вход в [T-118](T-118-leadgen-legal-пдн-старая-база.md)
- [ ] **ИИ-дисклеймер** (не медицина) — ссылка на [ai-подсказки](../идеи/ai-подсказки-тренеру-границы-медицины.md)
- [ ] Ревью **директор** (30 мин): «можно резать dev P0»
