> Запрос директора: UI/UX-аудит раздела **конструктора тренировок** у тренера.

**Граница аудита:** Кабинет → **Тренировки** (упражнения + шаблоны + редактор) и связанный поток **назначения** из карточки клиента (иначе конструктор «в вакууме»).  
**Вне scope:** Client выполнение выполнения; полный редизайн визуала; billing.

**Критерии:** шаги до цели · консистентность с BR · мобильная плотность · empty/error · термины · стык шаблон → назначение.

## 2) Потоки (как сейчас)

```
База: Кабинет → Тренировки → [Упражнения | Шаблоны]
  Упражнение: инлайн-форма → список (edit = Dialog)
  Шаблон: «Новый шаблон» → POST пустой → полный редактор → «Сохранить шаблон»

Назначение: Клиенты → клиент → Тренировки → Назначения
  → выбрать шаблон → черновик на сервере → «Настроить»
  → править → «Назначить клиенту» / «Сохранить черновик»
```

## 4) Матрица находок

| ID | Экран | Проблема | Влияние | Сложн. | P |
|----|-------|----------|---------|--------|---|
| **WC-01** | Редактор шаблона | Карточка на каждое «Задание» + ряд 3–5 number inputs (`stacked`) — плотно на 360px | Долгое редактирование, промахи по полям, скролл-марафон | M | **P1** |
| **WC-02** | Создать шаблон | Сразу **POST пустого** шаблона; «Назад» без контента оставляет мусор в списке | Шум в библиотеке, путаница «Без названия» | S | **P1** |
| **WC-03** | Шаблон → назначение | Шаблон можно сохранить неполным; жёсткая валидация на **назначении** | Трение в момент «отдать клиенту»; непонятно, что дозаполнить | M | **P1** |
| **WC-04** | Назначения | Empty «Пока пусто.» без next-step CTA | Тупик, особенно без шаблонов | S | **P1** |
| **WC-05** | Упражнения | BR: «+» + отдельная страница; код: форма всегда сверху списка | Не как планы «+» / T-101 A4; экран шумный при полной базе | S | **P2** |
| **WC-06** | Конструктор ↔ клиент | Путь назначения 3–4 тапа; после T-101 A1 станет лучше, но связки «из шаблона назначить» в конструкторе нет | Разрыв mental model «собрал → отдал» | M | **P2** |
| **WC-07** | Назначение | Нет **просмотра глазами клиента** (состав до/после assign) | Ошибки в параметрах ловятся клиентом | M | **P2** |
| **WC-08** | Задание | Нет UI `per_set_params` / разные веса по подходам (есть в BR и схеме) | Сильные тренеры упираются в потолок MVP | L | **P2** |
| **WC-09** | Термины | «Задание» / «шаблон» / «Назначения» vs BR «Назначенные тренировки»; Voice почти пустой | Обучение онбордингом и поддержкой | S | **P2** |
| **WC-10** | Destructive | `window.confirm` на удаление шаблона/черновика/архив | Чужой паттерн (как UX-20) | S | **P3** |
| **WC-11** | Редактор | Reorder/delete — только icon buttons без подписей | Discoverability / a11y на мобиле | S | **P3** |
| **WC-12** | Тесты UI | Почти нет `data-testid` на builder (e2e на тексте) | Хрупкая автоматизация | S | **P3** |

## 5) Что уже хорошо

- Двухуровневая модель (упражнение → шаблон → назначение) соответствует ADR-002; «программы» убраны.
- Lead на хабе честно разделяет: библиотека общая, назначение — в клиенте.
- Редактор: комментарий, вес/время по флагам упражнения, отдых для timed.
- Назначения: черновик → активно → архив; копирование; e2e `workouts-v2.flow` закрывает happy path.
- Empty упражнений в редакторе ведёт ссылкой в базу.

## 6) Вердикт

Конструктор **рабочий для пилота**, но ощущается как **админ-форма**, не как инструмент тренера:

1. **P1:** плотность редактора, мусорные пустые шаблоны, разрыв валидации шаблон↔назначение, слабые empty на назначениях.  
2. **P2:** выровнять create упражнений с паттерном «+», deep-link «назначить из шаблона», preview, `per_set_params`, словарь.  
3. Не смешивать с T-101 срезом 2 (только вход через Кабинет) — отдельный implementation-пакет после приоритизации директором.

**Рекомендуемый порядок фиксов (если брать в работу):**

| Очередь | ID | Суть |
|---------|-----|------|
| 1 | WC-02, WC-04 | Не плодить пустые шаблоны; empty с CTA |
| 2 | WC-03 | Одинаковые правила полноты на save шаблона и assign (или явный «черновик шаблона») |
| 3 | WC-01 | Компактнее карточка задания (2 ряда полей / accordion) |
| 4 | WC-05, WC-09 | Паттерн «+» + Voice |
| 5 | WC-07, WC-08 | Preview; per-set — отдельным срезом |
