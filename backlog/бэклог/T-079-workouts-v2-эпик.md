## Контекст

Переход с трёх уровней (упражнение → комплекс → программа) на **два** (упражнение → **тренировка**). Программы упразднены; у клиента **несколько активных** назначений; новый UI выполнения с паузой, отдыхом и оркестратором.

**Канон:** [ADR-002](../../_telotron.ru/docs/Техдок/00-мета/архитектурные-решения/ADR-002-workouts-v2-dvuhurovnevaya-model.md) · [программы-тренировок v2](../../_telotron.ru/docs/Бизнес-требования/02-модули/m5-programmy-trenirovok/программы-тренировок.md) · [схема v2](../../_telotron.ru/docs/Техдок/03-модули/workout-тренировки-схема-данных-v2.md).

**Связано:** [T-077](../сделано/T-077-ui-технические-сообщения-стек.md) (действия в списках), [T-065](T-065-pro-onboarding-порядок-подготовка-клиент.md), [T-060](../сделано/T-060-pro-onboarding-k-p.md).

**Поставка:** Pro + Client **одним эпиком** — без клиентской части не закрываем.

## Критерии закрытия эпика

- [ ] Миграция: комплексы → тренировки; программы удалены; API v1 снят
- [ ] Pro: две вкладки конструктора; назначения с фильтрами и пагинацией 20
- [ ] Client: «Начать» → выбор → просмотр → выполнение с паузой и отдыхом
- [ ] Уведомления при назначении (лента + push/мессенджер)
- [ ] Тренер видит **завершённые** выполнения; клиент — полную историю
- [ ] Онбординг и глоссарий согласованы ([T-087](T-087-workouts-v2-onboarding-sign-off.md))
- [ ] Feature-тесты критичных сценариев + smoke E2E
