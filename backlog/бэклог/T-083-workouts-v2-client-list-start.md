## Контекст

Страница тренировок клиента: старт и просмотр перед выполнением.

## UI (канон)

1. Кнопка **«Начать»** сверху справа.
2. Окно выбора **активных** назначений; **клик по строке** = выбор тренировки.
3. **Краткий просмотр** состава → **«Поехали»**.
4. Ниже на странице — список **начатых сегодня** (без кнопок).
