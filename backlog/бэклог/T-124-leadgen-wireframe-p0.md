## Контекст

Wireframe **отладочного** CRM: простой список и карточка (этап, заметки, следующее действие).  
Не продукт для тренера в проде продаж — после ИИ экран не нужен как основной.

- [ ] Wireframe: список (фильтр по этапу)

- [ ] Wireframe: создание; поведение при склейке дубля (тост/баннер)
- [ ] Пометка в макете: «debug / feature-flag»
