## Контекст

Тренер пилота каждое утро получает 1–3 задачи на сегодня с «зачем». Код готовит кандидатов, ИИ выбирает и объясняет; при сбое — бриф по правилам. Канон — ADR-011.

## Критерии готовности

### Сигналы CRM → задачи
- [ ] Три сигнала (ADR-011 §2): новый контакт без касаний; следующее действие сегодня/просрочено; «в работе» > 7 дней без касания (порог в конфиге)
- [ ] Слушатели событий CRM + ежедневный проход по крону; дедупликация `(контакт, тип сигнала)`
- [ ] CRM читается через сервисы `Modules/Crm`; в CRM ничего не пишем

### Расчёт
- [ ] Кандидаты: открытые задачи на сегодня и просроченные (до 15) + цифры воронки + до 10 людей под макросами `{{name_N}}`
- [ ] Вызов `Modules/Ai`: `scenario=leadgen.morning_brief`, `json_schema`, модель и версия промпта из конфига
- [ ] Проверка ответа (ADR-011 §3) → иначе бриф по правилам, `source=rules`
- [ ] Маскирование: телефон / ник / канал / полное имя в LLM не уходят; подстановка имён после ответа
- [ ] Профиль не заполнен → одна задача «Заполните профиль», без вызова ИИ

### Хранение, свежесть, крон, лимиты
- [ ] Таблица брифов: тренер + локальная дата (уникально), пункты, `source`, `ai_run_id`, «устарел», время, счётчик ручных обновлений
- [ ] Отметка «устарел» по изменению задач и событиям CRM (новый контакт, смена этапа)
- [ ] Крон каждые 15 минут: `leadgen.brief_hour` (07:00) по часовому поясу тренера → job
- [ ] Лимит: 1 крон + 5 ручных «обновить» за локальные сутки; сверх — понятный отказ

### Доступ и API
- [ ] Галочка «пилот LeadGen» у тренера в Filament; флаг в ответе `/api/v1/me` (или features)
- [ ] `GET /api/v1/me/leadgen/brief`: нет брифа → синхронный расчёт; устарел → старый + `refreshing`, job в очередь; свежий → как есть
- [ ] `POST /api/v1/me/leadgen/brief/refresh` (лимит)
- [ ] Вне белого списка — 403

### Тесты (моки `Modules/Ai`)
- [ ] Сигналы и дедупликация; выбор только из кандидатов; невалидный ответ → правила; сбой провайдера → правила
- [ ] В запросе к ИИ нет телефона и ника; подстановка имён
- [ ] Крон по часовому поясу; лимит обновлений; «устарел» → `refreshing`; профиль не заполнен; 403 вне пилота
