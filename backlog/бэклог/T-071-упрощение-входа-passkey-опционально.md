## Контекст

**Рег. шаг 3 · «Для вашего удобства»**

- Линейка: «Пройдите 3 простых шага для регистрации».
- Текст: «Чтобы следующий раз не отправлять код, подключите вход через Ваш телефон».
- Кнопка регистрации Passkey (WebAuthn).

| Зона | Поведение |
|------|-----------|
| **Pro (пилот)** | **Обязательно** — нет «может быть позже»; **кабинет недоступен** до успешного WebAuthn |
| **Client (будущее)** | Опционально + «может быть позже» + подталкивание |

**Вход (не reg):** Passkey — [T-068](T-068-упрощение-входа-sms-бот-напоминания.md) + localStorage; при Passkey-login storage **не менять**.

**Подталкивание:** если Passkey не привязан — показывать рег. шаг 3 **раз в месяц** после авторизации (Pro: до привязки; Client: когда появится wizard).

**Прерванный reg:** не завершил шаг 3 → после login попадает на шаг 3.

## Критерии готовности

- [ ] Шаг 3 недоступен без завершённого рег. шага 2.
- [ ] Pro: нет «Позже»; **shell кабинета заблокирован** до WebAuthn (guard на все routes кроме wizard шага 3).
- [ ] После привязки: записать `passkey_credential_hint` в localStorage (для кнопки на странице телефона).
- [ ] Login: Passkey по правилам T-066; иначе SMS OTP.
- [ ] Monthly nudge для незавершённого Passkey.
- [ ] Recovery — [техдолг auth](../../../_telotron.ru/docs/Техдок/00-мета/техдолг-auth-после-этапа-1.md).
- [ ] Feature-тесты: Pro reg без skip; login Passkey не сбрасывает storage.
