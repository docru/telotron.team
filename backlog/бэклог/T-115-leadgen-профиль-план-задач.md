## Контекст

**День 1** онбординга: диалог/wizard профиля (специализация, цели, интенсивность, 1–2 соцсети, оффер) → **план на месяц / неделю / день**.  
v1 без ИИ: **rule-based** шаблоны по интенсивности ([инструменты §упрощённый помощник](../эпики/E-006-инструменты-приоритеты.md)).

## Критерии готовности

- [x] Модель **GrowthProfile** (или ADR-имя): поля из [описания §профиль](../эпики/E-006-описание-сервиса.md#как-начинается-работа--профиль-тренера)
- [x] Wizard / пошаговый UI (не длинная анкета); сохранение черновика — **API** (UI в T-137)
- [x] **План задач:** сущность Task с привязкой к дню/неделе; типы: профиль, база, страница, пост, касание (совещание — тип в enum, генератор v1 не создаёт)
- [x] Генерация **первой недели** по интенсивности (умеренный / плотный / лёгкий) + повторяющийся недельный шаблон
- [x] UI «задачи на сегодня» + отметка «сделано» — **API** (UI в T-137)
- [x] API + feature-тесты CRUD профиля и задач
- [x] **По ADR-011:** код в `app/Modules/LeadGen`; у задачи поля `source` (`plan` | `crm_signal`), `crm_contact_id` (nullable), ключ дедупликации; шаблон «зачем» у каждого типа задачи (для брифа по правилам)
- [x] Признак «профиль заполнен» доступен сервису брифа
- [x] `POST /api/v1/me/leadgen/tasks/{id}/done`

## Журнал

### 2026-10-02 (реализация)

- `Modules/LeadGen`: GrowthProfile, LeadGenTask, план (первая неделя + weekly), API `/me/leadgen/*`, флаг `leadgen_pilot` в Filament и `/me`.
- Анкета v1 без «денег/стиля»; TZ через `X-Timezone`; «совещание» в enum, в генераторе нет.
- Тесты: 9 feature + 5 unit.


- Анкета v1: специализация/аудитория, цель, старая база, 1–2 соцсети, время+срочность → интенсивность, оффер. Без «денег на рекламу» и «стиля».
- План: неделя 1 по «первым 7 дням» (± интенсивность), дальше повторяющийся недельный шаблон.
- Задачи без инструментов: текст + переход в CRM / страницу записи; «совещание» в v1 не генерировать.
