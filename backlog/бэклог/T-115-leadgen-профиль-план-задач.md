## Контекст

**День 1** онбординга: диалог/wizard профиля (специализация, цели, интенсивность, 1–2 соцсети, оффер) → **план на месяц / неделю / день**.  
v1 без ИИ: **rule-based** шаблоны по интенсивности ([инструменты §упрощённый помощник](../эпики/E-006-инструменты-приоритеты.md)).

## Критерии готовности

- [ ] Модель **GrowthProfile** (или ADR-имя): поля из [описания §профиль](../эпики/E-006-описание-сервиса.md#как-начинается-работа--профиль-тренера)
- [ ] Wizard / пошаговый UI (не длинная анкета); сохранение черновика
- [ ] **План задач:** сущность Task с привязкой к дню/неделе; типы: профиль, база, страница, пост, касание, совещание
- [ ] Генерация **первой недели** по интенсивности (умеренный / плотный / лёгкий)
- [ ] UI «задачи на сегодня» + отметка «сделано»
- [ ] API + feature-тесты CRUD профиля и задач
