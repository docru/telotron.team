## Контекст

Для баз **>30 человек** — загрузка таблицы (имя, контакт, комментарий).  
Желательно в первой версии продукта, после ручной формы.

## Критерии готовности

- [ ] Upload CSV/XLSX; маппинг колонок
- [ ] Preview + dedupe (по контакту)
- [ ] Ошибки построчно; частичный импорт
- [ ] Лимит строк (напр. 500) — из ADR
- [ ] Тесты: валидный/битый файл, дубликаты

## Вне scope

- Импорт из телефонной книги / ВК
