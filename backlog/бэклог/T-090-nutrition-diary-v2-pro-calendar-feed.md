## Контекст

`ClientCalendarFeedService` сейчас эмитит event `meal` на каждую плоскую запись. Канон: **1 event на приём** со сводкой.

## Поведение

- Тип `meal` сохранить для совместимости фронта Pro/Client calendar
- Заголовок: локализованный тип («Обед») + сводка блюд: `курица 150 г, рис 200 г`
- Время в ленте: **без часов**; сортировка внутри дня: З → О → У → П
- Фото: миниатюра слота если есть
- Пустой слот (только фото, без блюд) — event всё равно (подсветка дня у клиента)

## Критерии готовности

- [ ] Feed + feature-тест календаря с новой моделью
- [ ] Client calendar tab: лайтбокс meal показывает сводку слота
- [ ] Месячный вид: день с едой = любой слот с блюдом или фото
