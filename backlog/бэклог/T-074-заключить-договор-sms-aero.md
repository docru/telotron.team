## Контекст

На пилоте коды по СМС отправляем через [SMS Aero](https://smsaero.ru/). Директор (**Ю-1**): для **старта пилота** достаточно оплаты с личной карты **без** договора.

Перед выкладкой SMS/auth на **prod** (спринт 4, неделя D) и до **приёма платежей (01.09.2026)** — оформить **договор** (или иной документ по модели SMS Aero: оферта, DPA) с учётом ответов [Ю-2](../эпики/E-003-упрощение-входа.md) и правок [T-073](T-073-legal-смс-пилот-обновление-документов.md).

**Блокер 16.07:** договор ждёт **лист записи ОГРНИП**; оптимистично — лист ~17.07, выкладка до конца недели D.

## Задачи

| # | Задача |
|---|--------|
| 1 | Зарегистрировать/активировать аккаунт SMS Aero на **юрлицо** оператора (не личная карта) |
| 2 | Заключить договор / принять оферту SMS Aero; сохранить копию в `07-Юрист/` или внутреннем архиве |
| 3 | Согласовать с юристом: передача номера, текст СМС, статус SMS Aero в политике |
| 4 | При необходимости — обновить уведомление Роскомнадзора ([T-073](T-073-legal-смс-пилот-обновление-документов.md)) |
| 5 | Зафиксировать реквизиты и контакт в эксплуатационной доке (не секреты API в Git) |

## Критерии готовности

- [ ] Договор (или эквивалент) с SMS Aero подписан / принят.
- [ ] Оплата идёт с расчётного счёта оператора (или согласованная модель).
- [ ] Юрист подтвердил условия в рамках gate v2.0 (см. [Вопросы юристу §19](../../07-Юрист/Вопросы%20юристу.md)).
