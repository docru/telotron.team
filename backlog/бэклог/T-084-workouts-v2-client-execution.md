## Контекст

Экран выполнения: таймер, отдых, пауза, факт по подходам.

## Поведение (канон)

| Элемент | Правило |
|---------|---------|
| Одновременно | Одно незавершённое выполнение на клиента |
| «Далее» | В рамках подхода; по таймеру → автоотдых |
| Ряд кнопок | «Следующее упражнение» / «Пауза» / «Завершить тренировку» |
| Пауза | Сохраняется между заходами; таймер подхода **сбрасывается** |
| Факт | Значения тренера по умолчанию; изменение наследуется на подходы упражнения |
| Завершить досрочно | `completed` + `partial`; недоделанные упражнения в отчёте |
| Повтор | Новое выполнение; история неограниченна |
| Комментарий | Показ при выполнении из задания |

## Критерии готовности

- [ ] PATCH execution: полный JSON, idempotency на шаг
- [ ] Статусы `in_progress` / `paused` / `completed`
- [ ] Resume с паузы
- [ ] Офлайн: одно незавершённое на назначение
- [ ] Feature-тесты completion_percent
