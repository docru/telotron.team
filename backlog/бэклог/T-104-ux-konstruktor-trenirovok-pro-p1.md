## Scope

### WC-02 · создание шаблона

**Сейчас:** «Новый шаблон» → сразу `POST` пустого → редактор; «Назад» оставляет «Без названия» в списке.

**Нужно (выбрать один канон, предпочтительно A):**

| Вариант | Поведение |
|---------|-----------|
| **A (предпочтительно)** | Открыть редактор **без** POST; `POST` при первом успешном **«Сохранить шаблон»** (или debounce save). «Назад» без сохранения — ничего в списке. |
| **B** | POST как сейчас, но при уходе с пустым/безымянным шаблоном — **авто-DELETE** или confirm «Удалить черновик шаблона?». |

Не оставлять в списке безымянные пустые шаблоны без явного действия пользователя.

### WC-04 · empty назначений

В `ProClientWorkoutsPanel` (и пустой список шаблонов при add, если есть):

- Убрать тупик **«Пока пусто.»** без действия.
- Empty фильтра / списка: фраза + **CTA** (примеры):
  - нет назначений → **«Добавить тренировку»** (фокус на выбор шаблона);
  - нет шаблонов → ссылка/кнопка в **Кабинет → Тренировки → Шаблоны** («Создать шаблон»).

Стиль: как empty Клиенты / T-101 A8 (next-step).

### WC-03 · валидация шаблон ↔ назначение

**Сейчас:** шаблон часто сохраняется с дырами; на **«Назначить клиенту»** — жёсткий блок.

**Нужно:**

1. При **«Сохранить шаблон»** — та же проверка полноты заданий, что блокирует assign (переиспользовать `validateWorkoutTrainingTasks` / общий helper), **или** явный статус «черновик шаблона» с badge в списке (если оставляем неполный save — тогда badge обязателен).  
2. Предпочтительно для MVP: **нельзя сохранить шаблон**, который нельзя назначить (те же правила weight/time/rest).  
3. Сообщения ошибок — у задания / поля, не только toast на assign.  
4. Если assign всё ещё ловит ошибку — текст: что дозаполнить (не «Проверьте параметры» без указания).

### WC-01 · плотность редактора

`ProWorkoutTrainingTemplateEditorPage` + `WorkoutTrainingTaskRow` (`layout="stacked"`):

- На **360–430px** поля подходов/повторов/веса/времени/отдыха **не** в один ряд из 5 узких input.  
- Канон UX: **2 ряда** (например подходы|повторы|вес и время|отдых) или accordion «параметры» по умолчанию свёрнут для уже заполненных.  
- Карточка «Задание N» — меньше вертикального шума; reorder/delete оставить, подписи/aria не ухудшать.

Hi-fi не обязателен; сверка design QA после PR.
