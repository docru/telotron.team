## Контекст

Полные мастера краткого (К) и полного (П) онбординга признаны громоздкими: напрягают сильнее, чем помогают. Функционал мастеров снимается в рамках [T-101](../в-работе/T-101-ux-volna2-pro-ia-i-audit.md) (удаление кода / UI).

Вместо них — **один** виджет/слот подсказок: контекстный next-step, dismiss, без стека с install/offline.

Связь с идеей «Совет дня»: тот же механизм (не ротация trivia, а **действие**).

Предшественник: [T-060](../сделано/T-060-pro-onboarding-k-p.md) (реализован, решение — заменить nudges).

## Цель

Тренер видит **не чаще одной** релевантной подсказки («Пригласите клиента», «Создайте занятие», …) в контексте экрана; может закрыть; повтор — по правилам (не каждый заход с тем же текстом без причины).

## Scope (черновик до design)

- [ ] Один UI-слот в Pro shell (или на ключевых страницах: Клиенты, Кабинет) — **не** отдельный wizard route.
- [ ] Правила показа: приоритет 1 nudge; dismiss навсегда / «позже»; условия по данным (нет клиентов → invite и т.д.).
- [ ] Copy 2–4 подсказок (PO + дизайнер) — простой язык, без тарифов.
- [ ] Не дублировать offline/install/channels banners (max 1 persistent + очередь, см. UX-19).
- [ ] Client zone — **вне** MVP этого тикета (отдельно, если понадобится).

## Вне scope

- Возврат мастеров К/П, чеклист «Продолжить настройку», spotlight-тур по всем якорям.
- Ротация «фактов дня» без CTA.

## Критерии готовности

- [ ] Мастера сняты (зависимость: срез удаления в T-101) — иначе два UX сразу.
- [ ] Виджет показывает ≤1 подсказку; dismiss сохраняется.
- [ ] Подсказки ведут deep link в нужный раздел.
- [ ] Smoke 360px: слот не вытесняет primary CTA страницы.
- [ ] Тесты на правила показа / dismiss.
