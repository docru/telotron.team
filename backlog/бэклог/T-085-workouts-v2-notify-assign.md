## Контекст

При переходе назначения в `active` («Назначить») клиент получает уведомление.

## Канон

- Запись в **ленту** клиента (feed).
- **Push** и/или **мессенджер** — если каналы подключены (существующий контур Reminders/ботов).

## Критерии готовности

- [ ] Событие при `assign` только из `draft`
- [ ] Лента: тип события «новая тренировка»
- [ ] Push/мессенджер — best effort, не блокер при недоступности канала
- [ ] Тест: назначение → клиент видит в ленте
