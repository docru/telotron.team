> Запрос директора: UI/UX-аудит **формы ввода еды** у клиента (дневник питания: блюдо + фото + слоты).

**Граница:** `/nutrition?sub=diary` — неделя, 4 слота, compose блюда, голос, вес, фото, clear/delete.  
**Вне scope:** план питания (файл от тренера); Pro feed; идеи КБЖУ / штрихкод / AI.

**Критерии:** шаги до «записал» · плотность на 360px · empty/error/offline · фото · термины · сверка с E-005.

## 1) Инвентарь

| Элемент | Где |
|---------|-----|
| Дневник | `ClientNutritionDiaryPage.vue` |
| Хаб Питание | `ClientCalendarPage.vue` — вкладки Дневник / Назначения |
| Фото lightbox | `NutritionMealPhotoLightbox.vue` |
| Сжатие | `meal-photo-compress.ts` |
| Outbox | nutrition_* kinds в outbox |

**Модель дня (канон E-005):** 4 слота — Завтрак / Обед / Ужин / Перекус; много блюд в слоте; **1 фото на приём**.

**Входы:** tab Питание · home «Питание» · default `sub=diary` (T-101 A6 ✅).

**Поток блюда:** день на полоске → **+** на слоте → compose (название + mic + вес + ед.) → **Сохранить**.

**Поток фото:** камера/галерея (`input file`, без `capture`) → compress → upload; есть фото → lightbox → Заменить / Удалить.

## 4) Что уже хорошо

- 4 слота + полоска недели соответствуют E-005 / T-101 «Дневник».
- Default tab дневник (не «календарь»).
- Несколько блюд в приёме; clear приёма; edit карандашом.
- Сжатие фото на клиенте; outbox для create/patch/delete блюд и photo upload.
- Будущие дни недоступны для записи.

---

## 5) Вердикт

Форма **рабочая для пилота**, но ввод еды ощущается как **плотный админ-compose**, а фото — как «файл в форму», не как быстрый снимок приёма.

1. **P1:** упростить compose (или sheet на блюдо — в духе профиля/шаблонов); empty с CTA; не навязывать 100 г; фото с превью / capture.  
2. **P2:** offline thumb + delete photo outbox; Dialog вместо confirm; Voice «ты»; общий week picker.  
3. E2E и чистка legacy copy — P3.

**Рекомендуемая очередь**

| # | ID | Суть |
|---|-----|------|
| 1 | NF-01, NF-03 | Compose: sheet или 2 шага (название → вес); вес пустой / обязательный явно |
| 2 | NF-02 | Empty дня / слота с CTA «Добавить блюдо» |
| 3 | NF-04 | Превью фото до upload; `capture` где уместно |
| 4 | NF-05…09 | Offline UX, Dialog, Voice, общий strip |
| 5 | NF-10…12 | Legacy / E2E / draft discard |
