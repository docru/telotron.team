## Критерии готовности

- [ ] Раздел «Поиск клиентов» в Pro (новый маршрут; виден только при флаге пилота)
- [ ] Карточка брифа вверху раздела: 1–3 задачи, «зачем», «сделано», «обновить»
- [ ] Пометка «без ИИ» при `source=rules`
- [ ] `refreshing`: показываем старый бриф, один перезапрос и подмена
- [ ] Лимит обновлений исчерпан → понятное сообщение, кнопка неактивна
- [ ] Профиль не заполнен → задача «Заполните профиль — 15 минут» с переходом в мастер
- [ ] Home-виджет `leadgen_brief` (только Pro, только при флаге) по [канону виджетов](../../../_telotron.ru/docs/Техдок/01-канон-mvp/frontend-home-виджеты-главной-mvp.md) — **P1**: если не успеваем к пилоту, остаётся только карточка
- [ ] Работает в PWA и в host-средах (RuntimeAdapter, ADR-008)
- [ ] Vitest на состояния карточки; `npm run build`; поднять `build.pro`
