## 4) Топ улучшений (рекомендация дизайнера)

### Quick wins (1–2 спринта, без редизайна shell)

1. **Client home (UX-11):** один primary блок «Сейчас главное» + максимум один secondary; трекеры — компактнее или под fold; Записаться/Прогресс — не конкурировать с primary.
2. **Nutrition default (UX-12):** `defaultSubTabForSection('nutrition')` → `diary` (как порядок вкладок и home CTA).
3. **Clients empty (UX-14):** empty CTA = «Пригласить клиента» (открыть тот же dialog).
4. **Словарь терминов (UX-15):** канон в Voice + единые label для одного виджета (Дневник **или** Календарь — выбрать одно для обеих зон).
5. **States (UX-22):** шаблон empty/error/offline с next-step на: Clients, Schedule, Client home, Client hubs, Hub Pro.

### Системные (волна 2–3)

6. **Pro Client Hub (UX-13):** убрать одновременные 2 ряда табов — секции как segmented primary; подконтекст — sheet или один уровень.
7. **Трекеры Client (UX-16):** один канонический экран правки; home = summary + deep link; calendar day = read-only summary.
8. **IA «Ещё» (UX-17):** решить с PO, что поднимать в табы/quick actions после feedback пилота (не трогать без данных).
9. **Паттерн create (UX-18):** dialog/sheet для create на Groups/Plans как на Schedule.
10. **Banner stack (UX-19):** max 1 persistent banner + очередь (как one-time lightbox T-024).

### Не трогать сейчас

- Полный редизайн shell / табов.
- Упрощение регистрации ниже юр. минимума (UX-06) — только микрокопи и прогресс-индикатор.
- Billing/partner UI — только соблюдать guardrails T-057 §5.
