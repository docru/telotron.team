> Запрос директора: UI/UX-аудит страницы **профиля** у тренера (Pro) и клиента (Client).

**Граница:** `/profile`, вход из шапки / Кабинета, связанный `/notification-channels`, passkey, «Мои часы», logout / приватность.  
**Вне scope:** полный legal-гейт, регистрация, billing; фото профиля как фича (отметить gap).

**Критерии:** шаги · discoverability · плотность · empty/error · термины · Pro≠Client без путаницы · соответствие T-101 B2.

## 1) Инвентарь

Один экран на обе зоны: `WorkspaceProfilePage.vue` (`/profile`).

| Блок | Pro | Client |
|------|-----|--------|
| Аккаунт (телефон, email) | ✅ read-only | ✅ |
| Анкета (имя, фамилия, пол, ДР) | ✅ | ✅ (обязательна при `anketa=1`) |
| Имя для клиентов | ✅ | — |
| **Мои часы** | ✅ | — |
| Passkey | ✅ | ✅ (скрыто, пока анкета не заполнена) |
| Каналы оповещения → отдельная страница | ✅ | ✅ |
| Приватность (email удаления данных) | ✅ | ✅ |
| Выйти | ✅ | ✅ |

**Входы**

| Зона | Пути |
|------|------|
| Pro | Кабинет → «Профиль» + иконка в шапке (`CircleUser`) |
| Client | Только иконка в шапке; force `/profile?anketa=1` при незаполненной анкете |

**Нет UI:** смена телефона, пароль, timezone picker, фото, удаление аккаунта (только email для запроса).

## 4) Что уже хорошо

- Единый `/profile` — меньше дублирования маршрутов.
- Pro: два входа (Кабинет + шапка) по духу B2.
- «Мои часы» с пояснением про сетку Расписания.
- Каналы вынесены на отдельную страницу (не всё в одном экране).
- Телефон маскируется; анкета с обязательными полями и валидацией.
- Passkey формулировка человеческая («отпечаток / Face ID»).

| **PF-03** | **Гейт** (`anketa=1`): после save можно увести на home, но **с сообщением** успеха (toast / короткий экран). **Обычное** редактирование анкеты — **остаёмся** на профиле + «Анкета сохранена». |
| **PF-04** | Title stack Pro (см. канон ниже) — согласуется со срезом 5 T-101. |

### Канон PF-04 · Pro «где я» (пояснение)

Сейчас после тапа «Профиль» в Кабинете экран выглядит как самостоятельная страница:

```
Профиль          ← только это
…
```

Непонятно, что ты всё ещё в зоне **Кабинета**, и нет явного «назад к списку плиток».

**Нужно** (как в wireframe T-101 §4.2) + срез 2 профиля:

```
← Кабинет
Кабинет / Профиль

Анкета
  Иван · …                    ›     ← сводки + sheet (не якоря)
…
```

Это не веб-крошки. Title stack + список блоков-сводок.
