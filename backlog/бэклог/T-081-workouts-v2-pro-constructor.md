## Контекст

Две вкладки «Тренировки»: **Упражнения** и **Шаблоны тренировок**. Раздел «Программы» убрать.

## UI (канон)

**Упражнения:** «+Добавить упражнение» сверху справа; список; страница создания/редактирования.

**Шаблоны:** список; редактор заданий с полем **комментарий**; для упражнений на время — **время подхода** и **отдых** обязательны.

## Критерии готовности

- [ ] CRUD упражнений и шаблонов через API v2
- [ ] Валидация `rest_seconds` при `time_seconds`
- [ ] Удаление упражнения — 409 при использовании
