## Контекст

Полноэкранный / блокирующий мастер **не обязателен**. Сразу после reg — **приглашающий баннер** («начать знакомство» / «настроить за 15 мин»), кабинет доступен сразу.

Стык с [T-060](../в-работе/T-060-pro-onboarding-k-p.md) (coach-bar), [T-065](T-065-pro-onboarding-порядок-подготовка-клиент.md) (порядок шагов). F-13.

## Критерии готовности

- [ ] Первый вход после reg → **расписание** (или home зоны), **не** принудительный `/onboarding`.
- [ ] Баннер CTA: «Начать настройку» → мастер / coach-bar; **«Позже»** dismiss без блокировки shell.
- [ ] Повторный вход в мастер из «Ещё» / «Продолжить настройку» (канон T-060).
- [ ] Не конфликтует с T-067 (PWA nudge) — приоритет показа согласован.
- [ ] Порядок шагов мастера по [T-065](T-065-pro-onboarding-порядок-подготовка-клиент.md) после merge T-060 pause.
- [ ] E2E/smoke: reg → кабинет без прохождения мастера; баннер → один шаг мастера открывается.
