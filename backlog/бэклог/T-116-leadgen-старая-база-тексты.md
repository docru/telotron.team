## Контекст

**День 2:** список «бывших» / неактивных контактов + **готовые тексты** для личных сообщений (ВК, ТГ, Макс).  
Тренер **копирует и шлёт сам** — без исходящих из Telotron в v1.

## Критерии готовности

- [ ] Модель **ReactivationContact:** имя, канал связи, последний раз, статус, заметка ([описание §старая база](../эпики/E-006-описание-сервиса.md#старая-база--как-заносим-людей))
- [ ] Статусы: не писали / написали / ответил / отказ / пробная / снова клиент / **не беспокоить**
- [ ] UI: простая форма + список + карточка; задача «кому написать сегодня» (5–10)
- [ ] **Антисpam:** лимит N сообщений/день по интенсивности; пауза 3–5 дней между касаниями одному
- [ ] **Шаблоны текстов** с подстановкой (имя, специализация, ссылка на запись — после [T-117](T-117-leadgen-страница-записи.md))
- [ ] Кнопка «скопировать текст»; без автоотправки
- [ ] Не дублировать активных Client M1
- [ ] Тесты: CRUD, лимиты, статусы
