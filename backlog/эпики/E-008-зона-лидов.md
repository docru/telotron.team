**Цель.** Отдельная зона **welcome-clients** для лидгена: форма обратного звонка и квиз по ссылке тренера. Заявки → **контакты CRM** (E-006). В кабинете Pro — временный раздел CRM (колбек / квиз).

**Не цель.** Каналы (E-009), ИИ-чат (E-010), воронка как продукт.

## Вводная (2026-09-23)

- Зона: `welcome-clients.telotron.ru` · `/callback/{ник}`, `/quiz/{ник}`
- Pro: CRM → колбек / квиз (настройки + списки) — **временный** UI
- **Лид** = контакт со статусом **«новый»** (не отдельная сущность)
- Заявка → **контакт CRM** (не пользователь). Пользователь Client — только при переходе в статус **«клиент»** (если ещё не привязан)
- Если User уже есть — связываем; клиентские данные скрыты до статуса **«клиент»**
- **Новый** User — только регистрация по **разовой пригласительной ссылке** с контакта
- **Чужого существующего** User тренер может **перевести в клиента** (явный шаг)
- Контакт другого тренера не показываем; своя заявка в списке видна

### Правила ника (Q17)

| Правило | Значение |
|---------|----------|
| Символы | Только `a–z`, `0–9`, дефис `-` |
| Регистр | Сразу в **нижний**; так и храним |
| Длина | **3–32** |
| Дефис | Не в начале/конце; не `--` подряд |
| Уникальность | Глобально один на всех тренеров |
| Зарезервировано | `callback`, `quiz`, `api`, `www`, `admin`, `pro`, `client`, `login`, `register`, `static`, `assets` (+ расширение позже) |
| UI | Подсказка + маска (лишнее не вводится) + ошибки валидации / «ник занят» |
