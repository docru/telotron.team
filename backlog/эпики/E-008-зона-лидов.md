# E-008 — Зона лидов

| Поле | Значение |
|------|----------|
| **Статус** | `planned` |
| **Приоритет** | P0 |
| **Инициатива** | [I-001 Модуль продаж](../инициативы/I-001-модуль-продаж.md) |
| **Владелец** | продукт + разработка |
| **Связанные** | [E-006](E-006-crm-тренера.md), [E-009](E-009-кросплатформенность.md), [E-010](E-010-ии-консультант-продаж.md) |

**Цель.** Отдельная зона опыта для кандидата (лида): вход/лендинг тренера, заявка, минимальный путь до контакта с тренером — без полноценной CRM-карточки на стороне лида.

**Не цель.** CRM в Pro (E-006), мессенджер-каналы (E-009), ИИ-диалог (E-010).

## Сроки (ориентир)

| Веха | Срок | Критерий |
|------|------|----------|
| MVP зоны лидов | после MVP CRM (E-006); ориентир Q4 2026 | лид оставляет заявку / попадает в воронку тренера |

## Этапы

### Этап 1 — Поверхность лида
- [ ] Публичная/полупубличная точка входа (ссылка тренера)
- [ ] Форма заявки / минимальный профиль интереса

### Этап 2 — Связь с CRM
- [ ] Создание **`CrmContact`** в CRM (E-006) из заявки — [ADR-006](../../../_telotron.ru/docs/Техдок/00-мета/архитектурные-решения/ADR-006-crm-headless.md)
- [ ] Уведомление тренера

### Этап 3 — Расширения
- [ ] Готовность принимать лидов из каналов (E-009)
- [ ] Хуки для ИИ-консультанта (E-010) без обязательного включения

## Acceptance

- [ ] Лид проходит путь заявки без аккаунта Client (или с минимальным — по решению продукта)
- [ ] Заявка видна тренеру в CRM со статусом «новый»

## Заметки

Часть бывшего скоупа «поиск клиентов» / DEC-008 «зона лидов».
