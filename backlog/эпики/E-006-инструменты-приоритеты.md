## Приоритетные волны

### P0 · «Первая неделя работает» (MVP для тренера)

Цель: тренер проходит [план 7 дней](E-006-описание-сервиса.md#первые-7-дней-после-подключения) **без обучения CRM**.

| Инструмент | Зачем в P0 | Зависимости |
|------------|------------|-------------|
| Профиль | День 1; план, интенсивность, 1–2 соцсети | — |
| Старая база | День 2; самый быстрый канал | юр. минимум по ПДн «бывших» |
| Готовые тексты | День 2–5; тренер шлёт сам | профиль + база |
| Страница записи | День 3; ссылка в сообщения и пост | M2 запись/заявка |
| План задач | Каждый день; «что сделать и зачем» | профиль |

**Соотношение полезность/сложность:** максимальное. Большая часть — **не ИИ**, а **структура + данные + ссылка**.

### P1 · «Помощник и замыкание цепочки»

| Инструмент | Зачем в P1 | Заметка |
|------------|------------|---------|
| Учёт лидов | Заявки со страницы, статусы базы, день 6–7 | Не показывать как «воронку» |
| Умный помощник | Центр UX: советы, тексты, перестройка плана | Caila, guardrails, лимиты |
| Совещание | День 7 и дальше; удержание в модуле | Можно начать как сценарий в чате |
| Идеи постов | День 4+ | Частично = ответы помощника |
| Импорт файла | База >30 человек | После ручной формы |

### P2 · «Умнее по цифрам и шире профили»

- **Наращивание по этапам** — когда есть хоть какие-то метрики (заявки, пробные, посты).
- **Шаблоны нутрициолог / тренер** — контент и промпты, не новая архитектура.
- **Commerce gating** — продуктово обязательно для аддона, но **не блокирует** внутренний пилот модуля.

### P3 · «Каналы и автоматизация»

- ВК / Mini App, «приведи друга», отправка из приложения, геореклама — **после** работающей связки база → страница → заявка → пробная.

## Упрощённый помощник (если ИИ не успевает в срок)

Чтобы **не сдвигать P0**, допустим промежуточный слой:

| Функция помощника | v1 без полного ИИ | v1 с ИИ |
|-------------------|-------------------|---------|
| Профиль | Пошаговый wizard + сохранение | Диалог |
| План на неделю | Шаблон по интенсивности + правила | Персональный план |
| Тексты | Шаблоны с подстановкой полей | Генерация + стиль |
| Совещание | Фиксированный чеклист + поля цифр | Разбор и рекомендации |
| Посты | 5–10 заготовок по специализации | Черновик под канал |

**Вывод:** P0 можно собрать **rule-based**; **P1** — подключить ИИ как **усиление**, не как единственный способ выдать текст.

## Что сознательно не в фокусе v1

| Не делаем сейчас | Почему |
|------------------|--------|
| Полноценная CRM «на виду» | Тренер не учит воронку — [описание сервиса](E-006-описание-сервиса.md) |
| Все соцсети сразу | 1–2 канала по профилю |
| Автоимпорт из телефона / ВК | Сложность + юр.; достаточно форма + файл |
| Марафоны «по моде» | Только по цифрам этапов (P2) |
| Публичный каталог платформы | Другой продукт, вне E-006 |
