# E-007 — Видео в конструктор

| Поле | Значение |
|------|----------|
| **Статус** | `planned` |
| **Приоритет** | P0 |
| **Инициатива** | [I-002 Инструменты дистанционного сопровождения](../инициативы/I-002-дистанционное-сопровождение.md) |
| **Владелец** | продукт + разработка |
| **Связанные** | [E-011](E-011-видеозапись-клиента.md), [E-012](E-012-трансляция.md); зависит от стабильности конструктора тренировок |

**Цель.** Встроить видео в конструктор тренировок / упражнений так, чтобы тренер мог опираться на видеоматериал в методике без отдельного «видео-продукта».

**Не цель.** Запись клиента с устройства (E-011), live-трансляция (E-012).

## Сроки (ориентир)

| Веха | Срок | Критерий |
|------|------|----------|
| Видео в конструкторе | декабрь 2026 | тренер прикрепляет/просматривает видео в контексте упражнения или блока |

## Этапы

### Этап 1 — Модель и хранение
- [ ] Сущность «видео» в контуре конструктора (метаданные, доступ, квоты — по канону монетизации при необходимости)
- [ ] Загрузка / привязка к упражнению или блоку

### Этап 2 — UI конструктора
- [ ] Просмотр в Pro при редактировании программы
- [ ] Отображение в Client при выполнении (минимум — по решению продукта)

### Этап 3 — Готовность к E-011 / E-012
- [ ] Контракты хранения и прав доступа переиспользуемы для записи клиента и трансляции

## Acceptance

- [ ] Тренер добавляет видео к элементу конструктора и видит его в рабочем сценарии
- [ ] Нет обязательной зависимости от live или записи с камеры клиента

## Заметки

Ранее файл `E-007-видео-в-конструктор.md` покрывал весь дистант; скоуп сужен. Запись и трансляция — отдельные эпики.
