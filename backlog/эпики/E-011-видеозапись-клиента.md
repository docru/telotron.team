# E-011 — Видеозапись клиента

| Поле | Значение |
|------|----------|
| **Статус** | `planned` |
| **Приоритет** | P1 |
| **Инициатива** | [I-002 Инструменты дистанционного сопровождения](../инициативы/I-002-дистанционное-сопровождение.md) |
| **Владелец** | продукт + разработка |
| **Связанные** | [E-007](E-007-видео-в-конструктор.md), [E-012](E-012-трансляция.md) |

**Цель.** Клиент записывает видео выполнения (с устройства) и передаёт тренеру для разбора в контуре сопровождения.

**Не цель.** Live-трансляция (E-012); библиотека методических роликов тренера в конструкторе (E-007) — переиспользует хранение/права по возможности.

## Сроки (ориентир)

| Веха | Срок | Критерий |
|------|------|----------|
| MVP записи | после E-007 или параллельно по ресурсу; ориентир 2027 | клиент загружает/отправляет запись, тренер открывает в Pro |

## Этапы

### Этап 1 — Захват и загрузка
- [ ] Запись или выбор файла в Client
- [ ] Привязка к заданию / упражнению / дате

### Этап 2 — Просмотр тренером
- [ ] Очередь / карточка записи в Pro
- [ ] Статус «просмотрено» / комментарий (минимум)

### Этап 3 — Квоты и приватность
- [ ] Срок хранения, согласия, удаление
- [ ] Связь с аддонами монетизации при необходимости

## Acceptance

- [ ] Клиент отправляет запись; тренер видит её в контексте сопровождения
- [ ] Нет требования к live-сессии

## Заметки

Часть бывшего E-007 «дистанционное сопровождение».
