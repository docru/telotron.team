# E-010 — ИИ-консультант продаж

| Поле | Значение |
|------|----------|
| **Статус** | `planned` |
| **Приоритет** | P1 |
| **Инициатива** | [I-001 Модуль продаж](../инициативы/I-001-модуль-продаж.md) |
| **Владелец** | продукт + [AI-инженер](../../11-AI-инженер/README.md) |
| **Связанные** | [E-006](E-006-crm-тренера.md), [E-008](E-008-зона-лидов.md), [E-009](E-009-кросплатформенность.md) |

**Цель.** Помощник продаж на базе LLM: квалификация лида, подсказки тренеру, ответы в зоне лидов / каналах — без обучения собственных моделей (интеграция провайдеров).

**Не цель.** Замена CRM; автономные сделки без тренера; bio/мед-советы вне продуктовых ограничений.

## Сроки (ориентир)

| Веха | Срок | Критерий |
|------|------|----------|
| Пилот на базе CRM + зона лидов | после E-006/E-008; ориентир 2027 H1 | тренер получает ИИ-подсказки или лид получает ограниченный диалог |

## Этапы

### Этап 1 — Контур интеграции
- [ ] Выбор провайдера / политики данных (PII, логи, отказы)
- [ ] Сценарии: подсказки тренеру vs диалог с лидом

### Этап 2 — Пилот
- [ ] Один сценарий end-to-end на данных CRM
- [ ] Метрики качества и эскалация к человеку

### Этап 3 — Каналы
- [ ] Подключение к E-009 при готовности каналов
- [ ] Аддон монетизации (если применимо по канону)

## Acceptance

- [ ] ИИ не пишет в обход статусов CRM без аудита
- [ ] Есть явный fallback на тренера
- [ ] Соответствует правилам роли AI-инженера (без обучения моделей с нуля)

## Заметки

Роль и границы: `Команда/11-AI-инженер/`.
