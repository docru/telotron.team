# E-012 — Трансляция

| Поле | Значение |
|------|----------|
| **Статус** | `planned` |
| **Приоритет** | P1 |
| **Инициатива** | [I-002 Инструменты дистанционного сопровождения](../инициативы/I-002-дистанционное-сопровождение.md) |
| **Владелец** | продукт + разработка |
| **Связанные** | [E-007](E-007-видео-в-конструктор.md), [E-011](E-011-видеозапись-клиента.md) |

**Цель.** Live-трансляция / онлайн-сессия тренер↔клиент(ы) в продукте или через контролируемую интеграцию.

**Не цель.** Асинхронная запись (E-011); статическое видео в конструкторе (E-007).

## Сроки (ориентир)

| Веха | Срок | Критерий |
|------|------|----------|
| Пилот трансляции | после базового видео-контура; ориентир 2027 | тренер и клиент проводят сессию с видеосвязью |

## Этапы

### Этап 1 — Выбор стека
- [ ] Build vs buy (WebRTC / провайдер)
- [ ] Модель сессии: 1:1 vs группа

### Этап 2 — MVP сессии
- [ ] Создание/вход в комнату из Pro/Client
- [ ] Базовый UX старт/стоп, индикаторы связи

### Этап 3 — Сопровождение
- [ ] Запись сессии (опционально) → стык с E-011
- [ ] Квоты, аддон, стабильность на мобильных

## Acceptance

- [ ] Тренер и клиент устанавливают видеосвязь по сценарию продукта
- [ ] Отказ провайдера/сети деградирует предсказуемо (понятная ошибка)
