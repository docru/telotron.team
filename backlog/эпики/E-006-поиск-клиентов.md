## 1) Зачем

Тренер тратит время на **переписку и ручной outreach**, а не на тренировки. Нужен **отдельный контур в Pro**, который помогает **привлечь клиентов с минимальными трудозатратами**: подсказки «что делать», воронка лидов, посадочная страница и каналы записи из соцсетей — в одном месте.

**Ценность для Telotron:** новый **платный аддон** (отдельная абонплата / upsell), дифференциатор vs «просто дневник+календарь», кейсы для outreach.

**Не путать с:**

| Что | Где |
|-----|-----|
| Партнёрка **тренер→тренер** (L1–L3) | [E-002](E-002-partner-модуль.md) |
| Публичный **каталог** платформы + продажа лидов | [идея](../идеи/публичный-каталог-тренеров-запись-лиды.md) — другой продукт, позже |
| CRM **команды** пилота (наши касания) | [T-063](../в-работе/T-063-crm-pilot-files.md) — не CRM тренера |

## 2) Продуктовый канон (черновик)

| Тема | Решение / гипотеза | Статус |
|------|--------------------|--------|
| Раздел Pro | Новый пункт меню / зона **«Поиск клиентов»** | ✅ рабочее имя |
| Цель модуля | Привлечение клиентов тренера **с минимальными трудозатратами** | ✅ |

### Составные части (треки)

```text
Поиск клиентов
├── A · ИИ-консультант по продвижению (чат)
├── B · CRM тренера (лиды / воронка)
├── C · Лендинг тренера (+ запись)
└── D · Соцсети / мини-приложения с быстрой записью
```

| Трек | Суть | Зависимости |
|------|------|-------------|
| **A · ИИ-консультант** | Чат в Pro: советы по продвижению, контент, приоритеты действий; без мед. советов | Caila / политики ИИ; граница [ai-подсказки](../идеи/ai-подсказки-тренеру-границы-медицины.md) |
| **B · CRM** | Воронка лидов (источник, статус, касания), не дублировать «карточки клиентов» M1 | [crm-старые-контакты](../идеи/crm-старые-контакты-реактивация.md), [риск слива](../идеи/crm-индикатор-риска-слива.md) |
| **C · Лендинг** | Публичная страница тренера + запись/заявка → Telotron | [тариф-максимум §2](../идеи/тариф-максимум-инструменты-роста.md), [геореклама](../идеи/геореклама-лендинг-тренера.md) |
| **D · Соцсети** | VK (и др.) · быстрая запись; тонкая оболочка над web/API | [vk-mini-app-zapis-trenera](../идеи/vk-mini-app-zapis-trenera.md): **фаза 1 web**, **фаза 2 Mini App** |

**Связанный задел идей:** [тариф-максимум · инструменты роста](../идеи/тариф-максимум-инструменты-роста.md) — этот эпик **собирает** лендинг/CRM/соцзапись + добавляет **ИИ-консультанта** и **явный раздел Pro** + **отдельную оплату**.

## 3) Границы и принципы

**В scope эпика**

- Раздел Pro «Поиск клиентов» (shell, навигация, gating).
- Чат с ИИ-консультантом по **маркетингу/продвижению** тренера.
- CRM-light лидов (не полноценный Salesforce).
- Лендинг + публичная запись/заявка.
- Каналы соцсетей с **быстрой записью** (минимум VK после web).
- Commerce: SKU / абонплата / TariffGate для модуля.
- Юр.: ПДн лидов, оферта аддона, тексты ИИ-дисклеймеров.

**Вне scope (пока)**

- Публичный каталог всех тренеров и CPL платформы.
- Агентство полного цикла / ведение рекламы «под ключ» без тренера.
- Оплата клиент→тренер (отдельная идея НПД).
- Медицинские рекомендации ИИ.

| Блокер | Зачем |

**Рекомендуемый порядок поставки (MVP модуля):**  
`0 Discovery` → **C1–C2 + B1–B3** (лендинг+CRM) → **A** (чат усиливает) → **D2** (VK) → polish / геореклама.

Альтернатива: сначала **A** как «тонкий» paid-аддон с чеклистами без лендинга — **хуже** (нет измеримого «клиент пришёл»), не рекомендовать как MVP.

## 6) Критерии закрытия эпика

- [ ] Раздел Pro **«Поиск клиентов»** доступен только при оплаченном аддоне/тарифе
- [ ] ИИ-чат по продвижению: ответ по делу, guardrails, лимиты, без мед. советов
- [ ] CRM: лид из лендинга/ручной ввод → статусы → переход в клиента/запись
- [ ] Лендинг тренера: заявка или запись попадает в контур Telotron
- [ ] Хотя бы **один** внешний канал быстрой записи (web обязателен; VK — целевой)
- [ ] Техдок + ADR + юр. минимум + тесты; runbook support
- [ ] Метрики: подключений аддона, лидов/нед., конверсия лид→запись (дашборд или admin)
