# Эпики

Крупные инициативы из **нескольких тикетов** T-XXX. Один файл = один эпик **E-XXX**.

Эпик **не** проходит папки `бэклог/` → `в-работе/` → `сделано/` — он всегда в **`эпики/`**; прогресс — в статусе файла и подтикетах.

## Нумерация

| Префикс | Назначение |
|---------|------------|
| **E-XXX** | Эпик (контейнер, критерии закрытия, очередь подтикетов) |
| **T-XXX** | Тикет (единица работы в спринте) |

Новый эпик: следующий свободный **E-XXX** по [`_шаблон-эпика.md`](_шаблон-эпика.md). Подтикеты — обычные T-XXX в [`бэклог/`](../бэклог/).

## Жизненный цикл

```text
идея / insight  →  эпик (E-XXX)  →  подтикеты (T-XXX)  →  в-работе  →  сделано
                         ↑
              статус эпика: backlog | in_progress | done
```

| Статус эпика | Когда |
|--------------|-------|
| `backlog` | Эпик согласован, подтикеты в очереди |
| `in_progress` | Хотя бы один подтикет в `в-работе/` |
| `done` | Критерии закрытия эпика ☑ (хвосты ops/legal — в отдельных T-XXX) |
