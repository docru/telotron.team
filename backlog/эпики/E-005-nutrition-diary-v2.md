## Контекст

Текущий дневник — **плоский список** записей (`nutrition_meals`: текст + фото). Нужна структура **приём пищи → блюда**, фиксированные слоты **завтрак / обед / ужин / перекус**, навигация по **неделе**, вес блюда (г/мл/шт.).

**Канон сейчас:** [nutrition-питание §5](../../_telotron.ru/docs/Техдок/03-модули/nutrition-питание-схема-данных-mvp.md) · [трекер §2](../../_telotron.ru/docs/Бизнес-требования/02-модули/m7-m13-трекер-и-вес/трекер.md).

**Вне эпика:** КБЖУ, штрихкод, ИИ — [идеи](../идеи/дневник-питания-штрихкод-кбжу.md), [идеи](../идеи/дневник-питания-ии-оценка-кбжу.md).

**Миграция данных:** старые `nutrition_meals` **удаляем** (записей на проде нет).

## Продуктовые решения (канон эпика)

| Тема | Решение |
|------|---------|
| Слоты | **4 в день**, по одному на тип: `breakfast` \| `lunch` \| `dinner` \| `snack` |
| UI дня | Всегда **4 карточки**; пустые — «Добавить блюдо» |
| День | `meal_date` в **TZ клиента**; по умолчанию сегодня; прошлое **редактируемо** |
| Время | **Нет**; в Pro порядок З → О → У → П |
| Блюдо | `name` + опц. `amount` + `amount_unit` (`g` \| `ml` \| `pcs`, default `g`) |
| Голос | На **каждое блюдо** |
| Удаление | Блюдо по одному; **«Очистить приём»** — все блюда + фото |
| Неделя | **Пн–Вс**, стрелки ±1 нед.; день подсвечен, если есть **блюдо или фото** |
| Скролл | На «сегодня» — к **текущему слоту** по времени суток |
| Фото | **1 на приём**; можно без блюд; замена перезаписывает |
| Pro feed | **1 event на приём** со сводкой блюд + миниатюра |

### Модель данных

```text
nutrition_meal_slots
  client_user_id, meal_date, meal_type
  UNIQUE (client_user_id, meal_date, meal_type)

nutrition_meal_dishes
  meal_slot_id, name, amount?, amount_unit?, sort_order

nutrition_meal_photos
  meal_slot_id  (1 фото, 14 суток — как сейчас)
```
